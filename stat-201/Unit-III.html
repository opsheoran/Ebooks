3.1 Concept of Linear Regression

While correlation measures the degree and direction of linear association between two variables, it does not imply functional dependence or enable prediction. Regression is the mathematical technique used to estimate or predict the unknown value of one variable (dependent variable) from the known value of another (independent variable).

The word regression (meaning "stepping back" or returning to mediocrity) was first used by Sir Francis Galton in 1877 while studying human inheritance—observing that tall parents tend to have sons who are taller than average, but shorter than their parents (regressing towards the population mean).

Definition: Linear Regression

Linear Regression models the expected value of a dependent variable \(Y\) as a linear function of an independent variable \(X\):

\[ E[Y | X] = a + bX \]

where \(a\) is the intercept and \(b\) is the regression coefficient (slope).

3.2 Two Lines of Regression

For a bivariate distribution \((X, Y)\), there are two distinct lines of regression:

  1. Regression line of Y on X: Used to estimate \(Y\) for a given value of \(X\).
  2. Regression line of X on Y: Used to estimate \(X\) for a given value of \(Y\).
1. Line of Regression of Y on X:
\[ (Y - \bar{Y}) = b_{yx} (X - \bar{X}) \]

where \(b_{yx}\) is the regression coefficient of Y on X:

\[ b_{yx} = \frac{ ext{Cov}(X,Y)}{\sigma_x^2} = r \frac{\sigma_y}{\sigma_x} \]
2. Line of Regression of X on Y:
\[ (X - \bar{X}) = b_{xy} (Y - \bar{Y}) \]

where \(b_{xy}\) is the regression coefficient of X on Y:

\[ b_{xy} = \frac{ ext{Cov}(X,Y)}{\sigma_y^2} = r \frac{\sigma_x}{\sigma_y} \]

3.3 Properties of Regression Coefficients

The regression coefficients \(b_{yx}\) and \(b_{xy}\) possess five fundamental properties:

Property 1: Geometric Mean equals Correlation Coefficient

The correlation coefficient \(r\) is the geometric mean of the two regression coefficients:

\[ r = \pm \sqrt{b_{yx} \cdot b_{xy}} \]

Property 2: Same Sign Rule

Both regression coefficients \(b_{yx}\) and \(b_{xy}\) must have the exact same algebraic sign as the correlation coefficient \(r\).

Property 3: Arithmetic Mean Inequality

The arithmetic mean of the two regression coefficients is greater than or equal to the absolute correlation coefficient:

\[ \frac{b_{yx} + b_{xy}}{2} \geq |r| \]

Property 4: Magnitude Reciprocity

If one regression coefficient is greater than unity (\(|b_{yx}| > 1\)), the other must be less than unity (\(|b_{xy}| < 1\)).

Property 5: Independence of Origin but Dependence on Scale

If \(U = \frac{X - a}{h}\) and \(V = \frac{Y - b}{k}\), then \(b_{YX} = \left(\frac{k}{h} ight) b_{VU}\).

3.4 Angle Between Two Regression Lines

Let \( heta\) be the acute angle between the two lines of regression:

\[ an heta = \left| \frac{1 - r^2}{r} ight| \cdot \frac{\sigma_x \sigma_y}{\sigma_x^2 + \sigma_y^2} \]
  • Case 1 (\(r = \pm 1\)): \( an heta = 0 \implies heta = 0^\circ\) (lines coincide).
  • Case 2 (\(r = 0\)): \( an heta = \infty \implies heta = 90^\circ\) (lines are perpendicular).

3.4 Regression Lines के बीच का कोण (\( heta\))

जब \(r = \pm 1\), दोनों रेखाएं coincide (\( heta = 0^\circ\)) होती हैं। जब \(r = 0\), रेखाएं लंबवत (\( heta = 90^\circ\)) होती हैं।

3.5 Standard Error of Estimate

Standard Error of Estimate of Y on X:
\[ S_{yx} = \sigma_y \sqrt{1 - r^2} \]
Standard Error of Estimate of X on Y:
\[ S_{xy} = \sigma_x \sqrt{1 - r^2} \]

3.6 Correlation Between Observed and Estimated Values

Theorem

The correlation coefficient between actual observed values \(Y\) and estimated values \(\hat{Y}\) is equal to \(|r|\):

\[ r(Y, \hat{Y}) = |r(X, Y)| \]

Observed values \(Y\) और estimated values \(\hat{Y}\) के बीच correlation coefficient \(|r|\) होता है।

3.7 Distinction Between Correlation and Regression

Feature Correlation Analysis Regression Analysis
Purpose Measures degree and direction of linear association. Predicts value of dependent variable from independent variable.
Symmetry Symmetric: \(r_{XY} = r_{YX}\). Asymmetric: \(b_{yx} eq b_{xy}\) in general.
Units Pure unitless number (\(-1 \le r \le 1\)). Has physical units (unit of Y / unit of X).

3.7 Correlation और Regression में अंतर

Correlation association मापता है, जबकि regression prediction प्रदान करता है।

3.8 Solved Numerical Examples

Example 3.1: Calculation of Regression Lines

Given \(\bar{X} = 36\), \(\bar{Y} = 85\), \(\sigma_x = 11\), \(\sigma_y = 8\), \(r = 0.66\). Obtain the regression lines and estimate \(Y\) when \(X = 50\).

Solution: \(b_{yx} = 0.66 imes (8/11) = 0.48\). Line: \(Y - 85 = 0.48 (X - 36) \implies Y = 0.48 X + 67.72\). For \(X = 50\): \(Y = 91.72\).

Q1. Define Linear Regression. Distinguish clearly between Correlation and Regression.
Solution:

Regression is the statistical method of modeling the functional or cause-and-effect relationship between a dependent variable Y and one or more independent variables X. Distinction: 1) Correlation measures degree of linear association; regression predicts dependent variable. 2) Correlation is symmetric (r_XY = r_YX); regression is asymmetric (b_yx ≠ b_xy). 3) Correlation is unitless; regression coefficients have physical units. 4) Correlation does not imply causation; regression assumes independent and dependent roles.

Q2. Derive the equation of the line of regression of Y on X using the principle of least squares.
Solution:

Let Ŷ = a + bX. Minimize S = Σ (y_i - a - b x_i)². Setting ∂S/∂a = 0 ⇒ Σ y_i = n a + b Σ x_i ⇒ a = ȳ - b x̄. Setting ∂S/∂b = 0 ⇒ Σ x_i y_i = a Σ x_i + b Σ x_i². Substituting a = ȳ - b x̄ gives b = [Σ x_i y_i - n x̄ ȳ] / [Σ x_i² - n x̄²] = Cov(X,Y) / σ_x² = b_yx. Thus (Y - ȳ) = b_yx (X - x̄).

Q3. State and prove the five important properties of regression coefficients.
Solution:

1) r = ± √(b_yx * b_xy) [Geometric mean is |r|]. Proof: b_yx * b_xy = r (σ_y/σ_x) * r (σ_x/σ_y) = r². 2) Both b_yx and b_xy have the same sign as r. Proof: σ_x, σ_y > 0. 3) (b_yx + b_xy)/2 ≥ |r|. Proof: (√b_yx - √b_xy)² ≥ 0 ⇒ (b_yx + b_xy)/2 ≥ √(b_yx b_xy) = |r|. 4) If one > 1, the other < 1. Proof: b_yx b_xy = r² ≤ 1. 5) Independent of origin, dependent on scale: If U=(X-a)/h, V=(Y-b)/k, then b_YX = (k/h) b_VU.

Q4. Derive the formula for the angle θ between two regression lines.
Solution:

Lines are Y - ȳ = b_yx (X - x̄) with slope m_1 = b_yx = r (σ_y/σ_x), and X - x̄ = b_xy (Y - ȳ) ⇒ Y - ȳ = (1/b_xy)(X - x̄) with slope m_2 = 1/b_xy = (1/r)(σ_y/σ_x). Using tan θ = |(m_2 - m_1)/(1 + m_1 m_2)| = |(1/b_xy - b_yx) / (1 + b_yx/b_xy)| = |(1 - b_yx b_xy) / (b_xy + b_yx)|. Substituting b_yx = r σ_y/σ_x, b_xy = r σ_x/σ_y gives tan θ = |(1 - r²)/r| * [σ_x σ_y / (σ_x² + σ_y²)].

Q5. Discuss the two extreme cases for the angle between regression lines: when r = 0 and when r = ±1.
Solution:

Case 1: When r = ±1, 1 - r² = 0 ⇒ tan θ = 0 ⇒ θ = 0°. The two regression lines coincide into a single straight line, indicating perfect linear relationship. Case 2: When r = 0, tan θ = ∞ ⇒ θ = 90°. The two lines are perpendicular to each other (Y = ȳ and X = x̄), indicating zero correlation.

Q6. Define Standard Error of Estimate S_yx. Derive its formula S_yx = σ_y √(1 - r²).
Solution:

S_yx² = (1/n) Σ (y_i - ŷ_i)² = (1/n) Σ [(y_i - ȳ) - b_yx (x_i - x̄)]² = (1/n) Σ (y_i - ȳ)² - (2 b_yx / n) Σ (x_i - x̄)(y_i - ȳ) + (b_yx² / n) Σ (x_i - x̄)² = σ_y² - 2 b_yx Cov(X,Y) + b_yx² σ_x². Substituting b_yx = Cov(X,Y)/σ_x² gives S_yx² = σ_y² - Cov(X,Y)²/σ_x² = σ_y² - r² σ_y² = σ_y² (1 - r²). Thus S_yx = σ_y √(1 - r²).

Q7. Prove that the correlation coefficient between observed values Y and estimated values Ŷ is |r|.
Solution:

Let Ŷ = ȳ + b_yx (X - x̄). Mean of Ŷ is E[Ŷ] = ȳ. Variance Var(Ŷ) = b_yx² σ_x² = r² σ_y². Covariance Cov(Y, Ŷ) = E[(Y - ȳ)(Ŷ - ȳ)] = b_yx E[(Y - ȳ)(X - x̄)] = b_yx Cov(X,Y) = r (σ_y/σ_x) * r σ_x σ_y = r² σ_y². Correlation r(Y, Ŷ) = Cov(Y, Ŷ) / [σ_y σ_Ŷ] = (r² σ_y²) / [σ_y * |r| σ_y] = r² / |r| = |r|.

Q11. Show that if one regression coefficient is greater than 1, the other must be less than 1.

Proof: b_yx * b_xy = r² ≤ 1. If b_yx > 1, then b_xy = r² / b_yx < 1 / b_yx < 1. Hence, both coefficients cannot simultaneously exceed unity.

Solution:

b_yx represents the average change in the dependent variable Y associated with a unit increase in the independent variable X. For example, if b_yx = 0.6 q/ha per kg fertilizer, it means yield increases by 0.6 q/ha for every additional kg of fertilizer applied.

Q14. State the condition under which the regression lines of Y on X and X on Y are parallel.
Solution:

The two regression lines are never parallel unless they coincide (when r = ±1) or are horizontal/vertical (when r = 0). When r = ±1, the lines coincide and have identical slopes.

b_yx = 40 / 100 = 0.4. b_xy = 40 / 64 = 0.625. r = √(0.4 * 0.625) = √0.25 = 0.5. σ_y = √(64/10) = √6.4 = 2.53. S_yx = σ_y √(1 - r²) = 2.53 * √(1 - 0.25) = 2.53 * 0.866 = 2.19.

By AM-GM inequality for positive numbers: (b_yx + b_xy)/2 ≥ √(b_yx b_xy) = |r|. For negative coefficients, (|b_yx| + |b_xy|)/2 ≥ |r| holds identically.

Q17. Explain why the regression line of Y on X should not be used to predict X from Y.

The line of Y on X is derived by minimizing vertical errors Σ(y_i - ŷ_i)², assuming X is known without error. To predict X from Y, horizontal errors Σ(x_i - x̂_i)² must be minimized, which yields the line of X on Y.

Y on X minimizes vertical errors Σ(y - ŷ)² to predict Y from X. X on Y minimizes horizontal errors Σ(x - x̂)² to predict X from Y. They intersect at (x̄, ȳ) and coincide only if r = ±1.

S_yx² = (1/n) Σ (y_i - ŷ_i)² = (1/n) Σ [(y_i - ȳ) - b_yx (x_i - x̄)]² = (1/n) Σ (y_i - ȳ)² - (2 b_yx / n) Σ (x_i - x̄)(y_i - ȳ) + (b_yx² / n) Σ (x_i - x̄)² = σ_y² - 2 b_yx Cov(X,Y) + b_yx² σ_x². Substituting b_yx = Cov(X,Y)/σ_x² gives S_yx² = σ_y² - Cov(X,Y)²/σ_x² = σ_y² - r² σ_y² = σ_y² (1 - r²). Thus S_yx = σ_y √(1 - r²).

Q7. Prove that the correlation coefficient between observed values Y and estimated values Ŷ is |r|.
Solution:

Let Ŷ = ȳ + b_yx (X - x̄). Mean of Ŷ is E[Ŷ] = ȳ. Variance Var(Ŷ) = b_yx² σ_x² = r² σ_y². Covariance Cov(Y, Ŷ) = E[(Y - ȳ)(Ŷ - ȳ)] = b_yx E[(Y - ȳ)(X - x̄)] = b_yx Cov(X,Y) = r (σ_y/σ_x) * r σ_x σ_y = r² σ_y². Correlation r(Y, Ŷ) = Cov(Y, Ŷ) / [σ_y σ_Ŷ] = (r² σ_y²) / [σ_y * |r| σ_y] = r² / |r| = |r|.

Q8. Given x̄ = 36, ȳ = 85, σ_x = 11, σ_y = 8, r = 0.66. Calculate the two regression lines and estimate Y when X = 50.
Solution:

b_yx = r (σ_y / σ_x) = 0.66 * (8 / 11) = 0.48. Line Y on X: Y - 85 = 0.48 (X - 36) ⇒ Y = 0.48 X - 17.28 + 85 ⇒ Y = 0.48 X + 67.72. For X = 50: Y = 0.48(50) + 67.72 = 24 + 67.72 = 91.72 q/ha. Line X on Y: b_xy = 0.66 * (11 / 8) = 0.9075. X - 36 = 0.9075 (Y - 85) ⇒ X = 0.9075 Y - 41.14.

Q9. The two regression lines are 8X - 10Y + 66 = 0 and 40X - 18Y - 214 = 0. Find x̄, ȳ, r, and ratio of standard deviations.
Solution:

Intersection (x̄, ȳ): Solve 8x̄ - 10ȳ = -66 and 40x̄ - 18ȳ = 214. Multiply first by 5: 40x̄ - 50ȳ = -330. Subtract: 32ȳ = 544 ⇒ ȳ = 17. 8x̄ = 10(17) - 66 = 104 ⇒ x̄ = 13. Slopes: From 8X - 10Y + 66 = 0 ⇒ Y = 0.8X + 6.6 ⇒ b_yx = 0.8. From 40X - 18Y - 214 = 0 ⇒ X = 0.45Y + 5.35 ⇒ b_xy = 0.45. Correlation r = √(0.8 * 0.45) = √0.36 = 0.6. Ratio σ_y / σ_x: b_yx = r (σ_y / σ_x) ⇒ 0.8 = 0.6 (σ_y / σ_x) ⇒ σ_y / σ_x = 4/3.

Q10. In a study on plant height X (cm) and leaf area Y (cm²), N = 10, ΣX = 150, ΣY = 220, ΣX² = 2450, ΣY² = 5100, ΣXY = 3500. Compute regression lines and S_yx.
Solution:

x̄ = 15, ȳ = 22. Σ(X-x̄)² = 2450 - 10(225) = 200 ⇒ σ_x² = 20. Σ(Y-ȳ)² = 5100 - 10(484) = 260 ⇒ σ_y² = 26. Σ(X-x̄)(Y-ȳ) = 3500 - 10(15)(22) = 200 ⇒ Cov(X,Y) = 20. b_yx = 200/200 = 1.0. Line Y on X: Y - 22 = 1.0 (X - 15) ⇒ Y = X + 7. b_xy = 200/260 = 0.769. Line X on Y: X - 15 = 0.769 (Y - 22). r = √(1.0 * 0.769) = 0.877. S_yx = √26 * √(1 - 0.769) = 5.099 * 0.480 = 2.45.

Q11. Show that if one regression coefficient is greater than 1, the other must be less than 1.
Solution:

Proof: b_yx * b_xy = r² ≤ 1. If b_yx > 1, then b_xy = r² / b_yx < 1 / b_yx < 1. Hence, both coefficients cannot simultaneously exceed unity.

Q12. If two regression lines are 3X + 2Y - 26 = 0 and 6X + Y - 31 = 0, find x̄, ȳ, and r.
Solution:

Solving 3x̄ + 2ȳ = 26 and 6x̄ + ȳ = 31: Multiply second by 2 ⇒ 12x̄ + 2ȳ = 62. Subtract first: 9x̄ = 36 ⇒ x̄ = 4. 2ȳ = 26 - 12 = 14 ⇒ ȳ = 7. Slopes: From first, Y = -1.5X + 13 ⇒ b_yx = -1.5. From second, X = -0.167Y + 5.167 ⇒ b_xy = -0.167. r = -√(-1.5 * -0.167) = -√0.25 = -0.5.

Q13. Explain the physical interpretation of the regression coefficient b_yx.
Solution:

b_yx represents the average change in the dependent variable Y associated with a unit increase in the independent variable X. For example, if b_yx = 0.6 q/ha per kg fertilizer, it means yield increases by 0.6 q/ha for every additional kg of fertilizer applied.

Q14. State the condition under which the regression lines of Y on X and X on Y are parallel.
Solution:

The two regression lines are never parallel unless they coincide (when r = ±1) or are horizontal/vertical (when r = 0). When r = ±1, the lines coincide and have identical slopes.

Q15. Given Σ(X-x̄)² = 100, Σ(Y-ȳ)² = 64, Σ(X-x̄)(Y-ȳ) = 40, N = 10. Compute b_yx, b_xy, r, and S_yx.
Solution:

b_yx = 40 / 100 = 0.4. b_xy = 40 / 64 = 0.625. r = √(0.4 * 0.625) = √0.25 = 0.5. σ_y = √(64/10) = √6.4 = 2.53. S_yx = σ_y √(1 - r²) = 2.53 * √(1 - 0.25) = 2.53 * 0.866 = 2.19.

Q16. Prove that the arithmetic mean of b_yx and b_xy is greater than or equal to |r|.
Solution:

By AM-GM inequality for positive numbers: (b_yx + b_xy)/2 ≥ √(b_yx b_xy) = |r|. For negative coefficients, (|b_yx| + |b_xy|)/2 ≥ |r| holds identically.

Q17. Explain why the regression line of Y on X should not be used to predict X from Y.
Solution:

The line of Y on X is derived by minimizing vertical errors Σ(y_i - ŷ_i)², assuming X is known without error. To predict X from Y, horizontal errors Σ(x_i - x̂_i)² must be minimized, which yields the line of X on Y.

Q18. Discuss the effect of change of scale on regression coefficients.
Solution:

If U = (X - a)/h and V = (Y - b)/k, then b_YX = (k/h) b_VU. Multiplying X by h reduces b_YX by factor h, while multiplying Y by k increases b_YX by factor k.

Q19. Show that if r = 0, the regression line of Y on X becomes Y = ȳ.
Solution:

Since b_yx = r (σ_y/σ_x) = 0, the equation (Y - ȳ) = b_yx (X - x̄) simplifies directly to Y - ȳ = 0 ⇒ Y = ȳ.

Q20. Calculate the angle θ between regression lines if r = 0.8.
Solution:

tan θ = |(1 - r²)/r| * [σ_x σ_y / (σ_x² + σ_y²)]. Assuming σ_x = σ_y: tan θ = |(1 - 0.64)/0.8| * (1/2) = (0.36 / 0.8) * 0.5 = 0.45 * 0.5 = 0.225. θ = arctan(0.225) ≈ 12.68°.

Q21. Explain how residual variance is calculated in linear regression.
Solution:

Residual variance is the mean of squared residuals: S_yx² = (1/n) Σ (y_i - ŷ_i)² = σ_y² (1 - r²). It represents the unexplained variance of Y after fitting the linear regression model.

Q22. Find the regression line of Y on X if x̄ = 10, ȳ = 20, σ_x = 2, σ_y = 3, r = 0.8.
Solution:

b_yx = 0.8 * (3 / 2) = 1.2. Equation: (Y - 20) = 1.2 (X - 10) ⇒ Y = 1.2 X - 12 + 20 ⇒ Y = 1.2 X + 8.

Q23. Show that b_yx * b_xy = r².
Solution:

b_yx * b_xy = [r (σ_y / σ_x)] * [r (σ_x / σ_y)] = r² (σ_y / σ_x) (σ_x / σ_y) = r².

Q24. Explain the principle of least squares as applied to regression lines.
Solution:

The line Y = a + bX is determined such that the sum of squared vertical deviations S = Σ (y_i - a - b x_i)² is minimized by setting ∂S/∂a = 0 and ∂S/∂b = 0.

Q25. If b_yx = 0.4 and b_xy = 0.9, test if these regression coefficients are valid.
Solution:

Check product: b_yx * b_xy = 0.4 * 0.9 = 0.36. Since 0.36 ≤ 1, r = √0.36 = 0.6 ≤ 1. Check same sign: both are positive. Hence, these coefficients are valid.

Q26. Explain why the slope of regression of Y on X is not equal to 1/b_xy in general.
Solution:

b_yx = r (σ_y/σ_x) and b_xy = r (σ_x/σ_y) ⇒ 1/b_xy = (1/r)(σ_y/σ_x). Thus b_yx = r² (1/b_xy). They are equal only when r = ±1.

Q27. In a bivariate data set, N = 25, r = 0.7, σ_y = 5. Find the Standard Error of Estimate S_yx.
Solution:

S_yx = σ_y √(1 - r²) = 5 * √(1 - 0.49) = 5 * √0.51 = 5 * 0.7141 = 3.57.

Q28. Distinguish between regression line of Y on X and regression line of X on Y.
Solution:

Y on X minimizes vertical errors Σ(y - ŷ)² to predict Y from X. X on Y minimizes horizontal errors Σ(x - x̂)² to predict X from Y. They intersect at (x̄, ȳ) and coincide only if r = ±1.

Q29. A scatter diagram shows a vertical line of points. What are the values of b_yx, b_xy, and r?
Solution:

If points lie on a vertical line, X is constant (Var(X) = 0). b_yx is undefined (division by zero), b_xy = 0, and r is undefined.

Q30. Explain how regression analysis is used in agricultural yield forecasting.
Solution:

Regression models express crop yield (Y) as a function of weather parameters, fertilizer dose, or soil moisture (X). By measuring X early in the season, farmers and policymakers predict harvest yield Y.
