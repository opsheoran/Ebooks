2.1 Concept of Curve Fitting

The general problem of finding equations of approximating curves that fit given sets of data is called curve fitting. Let us say you are given \(n\) pairs of data points \((x_i, y_i)\) for \(i = 1, 2, \dots, n\). Here, \(X\) is the independent variable and \(Y\) is the dependent variable. The goal is to find a mathematical relationship \(y = f(x)\) that best describes the trend in the data.

All measures studied in univariate statistics analyze a single variable (e.g. mean, variance). However, in agricultural, physical, and social sciences, observations are recorded simultaneously for two or more variables. For instance, height and weight of individuals, sales and profit of a firm, rainfall and crop production, or fertilizer dose and plant yield. In all these cases, we are interested in determining the best functional relationship connecting the independent variable \(X\) to the dependent variable \(Y\).

Objectives of Curve Fitting

  1. Data Summarisation: Replacing a large, complex table of scattered data points with a single, compact algebraic formula \(y = f(x)\).
  2. Interpolation & Extrapolation: Estimating the value of the dependent variable \(Y\) for a given value of \(X\) within the observed range (interpolation) or outside the observed range (extrapolation).
  3. Trend Analysis & Mathematical Modeling: Identifying underlying physical, biological, or economic laws governing the relationship between variables.

2.1 Curve Fitting का परिचय

दिया गया data points \((x_i, y_i)\) के समूह के लिए एक ऐसी mathematical equation \(y = f(x)\) खोजना जो data के सामान्य trend को सबसे अच्छी तरह दर्शाती है, Curve Fitting कहलाती है।

जहाँ univariate statistics केवल एक variable का अध्ययन करता है, वहीं curve fitting दो variables (जैसे वर्षा और फसल उत्पादन) के बीच सर्वश्रेष्ठ संबंध स्थापित करता है।

2.2 The Principle of Least Squares

Suppose we have \(n\) observed paired data points \((x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\). Let \(\hat{y}_i = f(x_i)\) be the estimated or expected value of \(Y\) calculated from the assumed curve for a given \(x_i\).

Definition: Residual (Error of Estimate)

The difference between the actual observed value \(y_i\) and the predicted value \(\hat{y}_i\) is called the residual or error for the \(i\)-th observation:

\[ e_i = y_i - \hat{y}_i = y_i - f(x_i) \]

The Principle of Least Squares

The Principle of Least Squares states that the curve of best fit is the one for which the sum of the squares of the residuals is minimized:

\[ S = \sum_{i=1}^{n} e_i^2 = \sum_{i=1}^{n} (y_i - f(x_i))^2 = ext{Minimum} \]

Why Do We Square the Errors?

  1. Prevention of Sign Cancellation: If we minimize the simple sum of errors \(\sum e_i\), positive errors (points above the curve) and negative errors (points below the curve) cancel each other out. A completely wrong curve could have \(\sum e_i = 0\).
  2. Calculus Differentiability: Minimizing the sum of absolute errors \(\sum |e_i|\) is mathematically difficult because the absolute value function lacks continuous derivatives at zero. In contrast, squared error functions \(e_i^2\) are smooth and easily differentiable.
  3. Penalty for Outliers: Squaring penalizes large deviations much more heavily than small ones, forcing the fitted curve to represent all data points fairly.

General Calculus Procedure for Obtaining Normal Equations

Let the curve equation be \(Y = f(X; a, b, c, \dots)\) containing unknown parameters \(a, b, c\). The sum of squared errors is:

\[ S(a, b, c, \dots) = \sum_{i=1}^{n} [y_i - f(x_i; a, b, c, \dots)]^2 \]

To minimize \(S\), we set the partial derivatives with respect to each parameter equal to zero:

\[ \frac{\partial S}{\partial a} = 0, \quad \frac{\partial S}{\partial b} = 0, \quad \frac{\partial S}{\partial c} = 0, \dots \]

Solving these simultaneous linear equations (known as Normal Equations) yields the best-fit parameters.

2.2 Principle of Least Squares

Principle of Least Squares के अनुसार सर्वश्रेष्ठ fit की रेखा वह होती है जिसके लिए residual errors के वर्गों का योग (\(\sum e_i^2\)) न्यूनतम (minimum) हो।

2.3 Fitting a Straight Line (\(Y = a + bX\))

Let the equation of the straight line to be fitted be:

\[ Y = a + bX \]

where \(a\) is the Y-intercept and \(b\) is the slope. Given \(n\) data points \((x_i, y_i)\), the residual sum of squares is:

\[ S = \sum_{i=1}^{n} (y_i - a - b x_i)^2 \]

Derivation of Normal Equations for Straight Line

Differentiating \(S\) partially with respect to \(a\) and \(b\) and setting to zero:

  1. \(\frac{\partial S}{\partial a} = -2 \sum_{i=1}^{n} (y_i - a - b x_i) = 0 \implies \mathbf{\sum Y = n a + b \sum X}\)
  2. \(\frac{\partial S}{\partial b} = -2 \sum_{i=1}^{n} x_i (y_i - a - b x_i) = 0 \implies \mathbf{\sum XY = a \sum X + b \sum X^2}\)
System of Normal Equations for Straight Line \(Y = a + bX\):
\[ \begin{cases} \sum Y = n a + b \sum X \\ \sum XY = a \sum X + b \sum X^2 \end{cases} \]

Simplification via Shift of Origin (\(\sum X = 0\))

When \(X\) values are equally spaced, we can shift the origin to the middle value \(X = A\):

\[ U = \frac{X - A}{h} \implies \sum U = 0 \]

Then the normal equations simplify directly to:

\[ a = \frac{\sum Y}{n} = \bar{Y}, \quad b = \frac{\sum U Y}{\sum U^2} \]

2.3 Straight Line Fitting (\(Y = a + bX\))

Straight line fit करने के लिए दो Normal Equations का उपयोग किया जाता है जो ऊपर दर्शाई गई हैं।

2.4 Fitting a Second-Degree Parabola (\(Y = a + bX + cX^2\))

When the scatter plot exhibits a curved (U-shaped or inverted U-shaped) trend, a second-degree polynomial or parabola is fitted:

\[ Y = a + bX + cX^2 \]

Derivation of Normal Equations for Parabola

Let \(S = \sum_{i=1}^{n} (y_i - a - b x_i - c x_i^2)^2\). Taking partial derivatives:

  1. \(\frac{\partial S}{\partial a} = 0 \implies \mathbf{\sum Y = n a + b \sum X + c \sum X^2}\)
  2. \(\frac{\partial S}{\partial b} = 0 \implies \mathbf{\sum XY = a \sum X + b \sum X^2 + c \sum X^3}\)
  3. \(\frac{\partial S}{\partial c} = 0 \implies \mathbf{\sum X^2 Y = a \sum X^2 + b \sum X^3 + c \sum X^4}\)
System of 3 Normal Equations for Parabola:
\[ \begin{cases} \sum Y = n a + b \sum X + c \sum X^2 \\ \sum XY = a \sum X + b \sum X^2 + c \sum X^3 \\ \sum X^2Y = a \sum X^2 + b \sum X^3 + c \sum X^4 \end{cases} \]

2.4 Second-Degree Parabola (\(Y = a + bX + cX^2\))

Parabola fitting के लिए 3 Normal Equations का उपयोग किया जाता है।

2.5 Fitting a Power Curve (\(Y = a X^b\))

The power curve equation is non-linear: \(Y = a X^b\). Taking base-10 logarithms on both sides converts it into a linear relationship:

\[ \log_{10} Y = \log_{10} a + b \log_{10} X \]
Linearized Power Model:

Let \(v = \log_{10} Y\), \(u = \log_{10} X\), \(A = \log_{10} a\), and \(B = b\). Then:

\[ v = A + B u \]
Normal Equations:
\[ \begin{cases} \sum v = n A + B \sum u \\ \sum u v = A \sum u + B \sum u^2 \end{cases} \]
Parameters: \(a = ext{antilog}_{10}(A) = 10^A\), and \(b = B\).

2.5 Power Curve (\(Y = a X^b\))

Power curve को logarithm लेकर linear form \(v = A + B u\) में बदल दिया जाता है।

2.6 Fitting Exponential Curves (\(Y = a b^X\) and \(Y = a e^{bX}\))

Exponential growth and decay curves are widely used in biology, compound interest, and crop growth modeling.

Form 1: \(Y = a b^X\)

Taking \(\log_{10}\) on both sides: \(\log_{10} Y = \log_{10} a + X \log_{10} b \implies v = A + B X\).

Normal equations: \(\sum v = n A + B \sum X\) and \(\sum X v = A \sum X + B \sum X^2\).

Parameter values: \(a = 10^A\), \(b = 10^B\).

Form 2: \(Y = a e^{bX}\)

Taking natural logarithm \(\ln\) on both sides: \(\ln Y = \ln a + b X \implies v = A + b X\).

Normal equations: \(\sum v = n A + b \sum X\) and \(\sum X v = A \sum X + b \sum X^2\).

Parameter values: \(a = e^A\), \(b = b\).

2.6 Exponential Curves

Exponential curves \(Y = a b^X\) और \(Y = a e^{bX}\) की प्रक्रिया ऊपर दर्शाई गई है।

2.7 Summary & Comparison of Curve Fitting Methods

Curve Type Equation Transformation Linear Form Parameters
Straight Line \(Y = a + bX\) None \(Y = a + bX\) \(a, b\)
Parabola \(Y = a + bX + cX^2\) None \(Y = a + bX + cX^2\) \(a, b, c\)
Power Curve \(Y = a X^b\) \(u = \log X, v = \log Y\) \(v = A + B u\) \(a = 10^A, b = B\)
Exponential 1 \(Y = a b^X\) \(v = \log Y\) \(v = A + B X\) \(a = 10^A, b = 10^B\)
Exponential 2 \(Y = a e^{bX}\) \(v = \ln Y\) \(v = A + b X\) \(a = e^A, b = b\)

2.8 Solved Numerical Examples

Example 2.1: Fitting a Straight Line

Fit a straight line \(Y = a + bX\) to the following agricultural data:

X (Fertilizer kg/ha)12345
Y (Yield q/ha)1427405568

Solution: Here \(N = 5\). \(\sum X = 15\), \(\sum Y = 204\), \(\sum X^2 = 55\), \(\sum XY = 748\).

Normal equations: 1) \(204 = 5a + 15b\), 2) \(748 = 15a + 55b\).

Solving simultaneously gives: \(b = 13.6\), \(a = 0\). The fitted line is \(\mathbf{Y = 13.6 X}\).

📝 Subjective Questions — 30 Questions

Q1. Define Curve Fitting. Discuss its main objectives and practical applications.
Solution:

Curve fitting is the mathematical procedure of finding a specific functional relationship y = f(x) that best describes the trend in a set of n paired observations (x_i, y_i). Objectives: 1) Data Summarisation: Replacing large tabular data with a compact formula. 2) Interpolation & Extrapolation: Estimating Y for X values inside or outside the observed range. 3) Trend Analysis: Identifying underlying physical, biological, or economic laws. Practical applications: Agricultural yield forecasting, crop response to fertilizer, population growth models, and sales forecasting.

Q2. State and explain the Principle of Least Squares. Why do we minimize squared errors instead of simple errors or absolute errors?
Solution:

Principle of Least Squares states that the curve of best fit is the one that minimizes the sum of squared residuals S = Σ (y_i - f(x_i))². Reasons for squaring: 1) Prevents sign cancellation: Simple sum Σ e_i can be zero for terrible fits due to positive and negative errors canceling out. 2) Differentiability: Absolute error function Σ |e_i| has sharp corners at zero and is non-differentiable, making calculus optimization difficult. 3) Outlier penalty: Squaring heavily penalizes large errors, forcing the curve to represent all data points fairly.

Q3. Derive the normal equations for fitting a straight line Y = a + bX using calculus.
Solution:

Let S = Σ e_i² = Σ (y_i - a - b x_i)². To minimize S, take partial derivatives with respect to a and b and set to zero: 1) ∂S/∂a = -2 Σ (y_i - a - b x_i) = 0 ⇒ Σ y_i = n a + b Σ x_i. 2) ∂S/∂b = -2 Σ x_i (y_i - a - b x_i) = 0 ⇒ Σ x_i y_i = a Σ x_i + b Σ x_i². These two equations are the Normal Equations for a straight line.

Q4. Explain the method of change of origin for fitting a straight line when X values are equally spaced.
Solution:

When X values are equally spaced, shift origin to the mid-value A: U = (X - A) / h. This makes Σ U = 0. The normal equations reduce to: 1) Σ Y = n a' ⇒ a' = Σ Y / n. 2) Σ U Y = b' Σ U² ⇒ b' = Σ U Y / Σ U². The line in transformed units is Y = a' + b' U. Converting back: a = a' - b' A / h, b = b' / h.

Q5. Derive the three normal equations for fitting a second-degree parabola Y = a + bX + cX².
Solution:

Let S = Σ (y_i - a - b x_i - c x_i²)². Taking partial derivatives: 1) ∂S/∂a = -2 Σ (y_i - a - b x_i - c x_i²) = 0 ⇒ Σ Y = n a + b Σ X + c Σ X². 2) ∂S/∂b = -2 Σ X_i (y_i - a - b x_i - c x_i²) = 0 ⇒ Σ XY = a Σ X + b Σ X² + c Σ X³. 3) ∂S/∂c = -2 Σ X_i² (y_i - a - b x_i - c x_i²) = 0 ⇒ Σ X²Y = a Σ X² + b Σ X³ + c Σ X⁴. These three simultaneous equations are solved for a, b, and c.

Q6. Show how a power curve Y = a X^b can be transformed into a linear form. Derive its normal equations.
Solution:

Take log base 10 on both sides: log Y = log a + b log X. Define v = log Y, u = log X, A = log a, B = b. The model becomes linear: v = A + B u. Normal equations in transformed variables: 1) Σ v = n A + B Σ u. 2) Σ u v = A Σ u + B Σ u². Solve for A and B. Then a = antilog(A) = 10^A, and b = B.

Q7. Explain the procedure for fitting the exponential curve Y = a b^X using logarithmic transformation.
Solution:

Take log base 10 on both sides: log Y = log a + X log b. Define v = log Y, A = log a, B = log b. The model becomes: v = A + B X. Normal equations: 1) Σ v = n A + B Σ X. 2) Σ X v = A Σ X + B Σ X². Solve for A and B. Parameter values: a = antilog(A), b = antilog(B).

Q8. Explain the procedure for fitting the exponential curve Y = a e^(bX) using natural logarithms.
Solution:

Take natural log ln on both sides: ln Y = ln a + b X. Define v = ln Y, A = ln a. The model becomes: v = A + b X. Normal equations: 1) Σ v = n A + b Σ X. 2) Σ X v = A Σ X + b Σ X². Solve for A and b. Parameter values: a = e^A, and b = b.

Q9. Fit a straight line Y = a + bX to the data: X = [1, 2, 3, 4, 5], Y = [14, 27, 40, 55, 68]. Predict Y for X = 7.
Solution:

N = 5. ΣX = 15, ΣY = 204, ΣX² = 55, ΣXY = 748. x̄ = 3, ȳ = 40.8. Normal equations: 1) 204 = 5a + 15b. 2) 748 = 15a + 55b. Multiply first by 3: 612 = 15a + 45b. Subtract from second: 136 = 10b ⇒ b = 13.6. 5a = 204 - 15(13.6) = 204 - 204 = 0 ⇒ a = 0. Line: Y = 13.6 X. For X = 7: Y = 13.6(7) = 95.2.

Q10. Fit a second-degree parabola Y = a + bX + cX² to data: X = [-2, -1, 0, 1, 2], Y = [15, 6, 3, 6, 15].
Solution:

N = 5. ΣX = 0, ΣX² = 10, ΣX³ = 0, ΣX⁴ = 34, ΣY = 45, ΣXY = 0, ΣX²Y = 90. Normal equations: 1) 45 = 5a + 10c. 2) 0 = 10b ⇒ b = 0. 3) 90 = 10a + 34c. From first: 5a = 45 - 10c ⇒ a = 9 - 2c. Substitute into third: 90 = 10(9 - 2c) + 34c ⇒ 90 = 90 - 20c + 34c ⇒ 14c = 0 ⇒ c = 0... Wait! 90 = 90 + 14c ⇒ c = 0? Check: X²Y = 4(15)+1(6)+0+1(6)+4(15) = 60+6+6+60 = 132. Correct ΣX²Y = 132. 132 = 10(9 - 2c) + 34c = 90 + 14c ⇒ 14c = 42 ⇒ c = 3. a = 9 - 2(3) = 3. Equation: Y = 3 + 3X².

Q8. Explain the procedure for fitting the exponential curve Y = a e^(bX) using natural logarithms.

Take natural log ln on both sides: ln Y = ln a + b X. Define v = ln Y, A = ln a. The model becomes: v = A + b X. Normal equations: 1) Σ v = n A + b Σ X. 2) Σ X v = A Σ X + b Σ X². Solve for A and b. Parameter values: a = e^A, and b = b.

Q9. Fit a straight line Y = a + bX to the data: X = [1, 2, 3, 4, 5], Y = [14, 27, 40, 55, 68]. Predict Y for X = 7.
Solution:

N = 5. ΣX = 15, ΣY = 204, ΣX² = 55, ΣXY = 748. x̄ = 3, ȳ = 40.8. Normal equations: 1) 204 = 5a + 15b. 2) 748 = 15a + 55b. Multiply first by 3: 612 = 15a + 45b. Subtract from second: 136 = 10b ⇒ b = 13.6. 5a = 204 - 15(13.6) = 204 - 204 = 0 ⇒ a = 0. Line: Y = 13.6 X. For X = 7: Y = 13.6(7) = 95.2.

Q10. Fit a second-degree parabola Y = a + bX + cX² to data: X = [-2, -1, 0, 1, 2], Y = [15, 6, 3, 6, 15].
Solution:

N = 5. ΣX = 0, ΣX² = 10, ΣX³ = 0, ΣX⁴ = 34, ΣY = 45, ΣXY = 0, ΣX²Y = 90. Normal equations: 1) 45 = 5a + 10c. 2) 0 = 10b ⇒ b = 0. 3) 90 = 10a + 34c. From first: 5a = 45 - 10c ⇒ a = 9 - 2c. Substitute into third: 90 = 10(9 - 2c) + 34c ⇒ 90 = 90 - 20c + 34c ⇒ 14c = 0 ⇒ c = 0... Wait! 90 = 90 + 14c ⇒ c = 0? Check: X²Y = 4(15)+1(6)+0+1(6)+4(15) = 60+6+6+60 = 132. Correct ΣX²Y = 132. 132 = 10(9 - 2c) + 34c = 90 + 14c ⇒ 14c = 42 ⇒ c = 3. a = 9 - 2(3) = 3. Equation: Y = 3 + 3X².
