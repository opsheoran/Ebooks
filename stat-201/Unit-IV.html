4.1 Introduction to Curvilinear Regression & Fitting of Curves

In agricultural, biological, and economic phenomena, the relationship between two variables is frequently non-linear or curved. For example, crop yield increases with fertilizer application up to an optimum point, after which excessive fertilizer causes yield to decline (Law of Diminishing Returns). Fitting a straight line to such data would introduce severe bias and inaccuracy. Curvilinear Regression (or Curve Fitting) provides mathematical techniques to fit non-linear curves to observed data using the Principle of Least Squares.

Formal Definition of Curve Fitting

Curve Fitting is the statistical procedure of finding a mathematical equation of a curve (such as a parabola, exponential, or power curve) that best describes the functional relationship between an independent variable (\(X\)) and a dependent variable (\(Y\)) across a set of sample data points.

The Principle of Least Squares (Foundation)

The standard criterion for determining optimal curve parameters is the Principle of Least Squares. For a set of \(n\) observed points \((x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\) and fitted values \(\hat{y}_i = f(x_i)\), the residual error is \(e_i = y_i - \hat{y}_i\).

The Principle of Least Squares minimizes the sum of squared residual errors:

\[ S = \sum_{i=1}^{n} e_i^2 = \sum_{i=1}^{n} \left[ y_i - f(x_i) \right]^2 \to \text{Minimum} \]

Overview of Non-Linear Curves & Linearization Transformations

  • Second-Degree Parabola: \(Y = a + bX + cX^2\) (Linear in parameters \(a, b, c\); solved via 3 normal equations).
  • Exponential Curve: \(Y = a b^X \implies \log Y = \log a + X \log b\) (Linearized via Common Logarithm).
  • Exponential Curve (Base e): \(Y = a e^{bX} \implies \ln Y = \ln a + b X\) (Linearized via Natural Logarithm).
  • Power Curve: \(Y = a X^b \implies \log Y = \log a + b \log X\) (Linearized via Double Logarithm).
  • Logarithmic Curve: \(Y = a + b \log X\) (Linearized via substitution \(U = \log X\)).
  • Inverse Curve: \(Y = a + \frac{b}{X}\) (Linearized via substitution \(U = \frac{1}{X}\)).

Example 4.1.1 (Scatter Plot Model Selection):

Problem: An agricultural experiment records Soil Salinity (\(X\) in dS/m) and Wheat Germination Rate (\(Y\) in %). Data shows that germination rate remains flat at 95% up to 4 dS/m, then drops rapidly. Explain why a straight line is unsuitable and which non-linear model should be selected.

Solution: A straight line assumes a constant rate of change (\(\frac{dY}{dX} = b\)), which fails to capture the threshold plateau followed by rapid decay. A non-linear curve such as a Second-Degree Parabola (\(Y = a + bX + cX^2\)) or an Exponential Decay curve (\(Y = a e^{-bX}\)) must be selected to capture the non-linear curvature.

Example 4.1.2 (Residual Sum of Squares Comparison):

Problem: For a dataset of 5 points, a straight line fit yields residual sum of squares \(SS_{linear} = 45.2\), while a parabola fit yields \(SS_{parabola} = 6.8\). Explain which model fits the data better.

Solution: The Principle of Least Squares selects the model that minimizes residual sum of squares. Since \(SS_{parabola} = 6.8 \ll SS_{linear} = 45.2\), the parabola accounts for significantly more variation and provides a superior fit.

4.1 Curvilinear Regression एवं Curve Fitting का परिचय

कृषि, जैविक, तथा आर्थिक परिघटनाओं में, दो variables के बीच संबंध अक्सर non-linear या घुमावदार (curved) होता है। उदाहरण के लिए, fertilizer डालने पर फसल उत्पादन एक अनुकूलतम बिंदु तक बढ़ता है, जिसके बाद अत्यधिक fertilizer से उत्पादन घटने लगता है (Law of Diminishing Returns)। ऐसे data पर सीधी रेखा फिट करने से गंभीर त्रुटि होगी। Curvilinear Regression (या Curve Fitting) Principle of Least Squares का उपयोग करके observed data पर non-linear curves फिट करने की सांख्यिकीय विधियाँ प्रदान करता है।

Curve Fitting की औपचारिक परिभाषा

Curve Fitting वह सांख्यिकीय प्रक्रिया है जिसके द्वारा observed data बिंदुओं के समूह पर independent variable (\(X\)) तथा dependent variable (\(Y\)) के बीच सर्वोत्तम संबंध दर्शाने वाले किसी curve (जैसे Parabola, Exponential, या Power Curve) का गणितीय समीकरण ज्ञात किया जाता है।

Principle of Least Squares (आधारभूत सिद्धांत)

सर्वोत्तम curve parameters निर्धारित करने का मानक मापदंड Principle of Least Squares है। \(n\) observed बिंदुओं \((x_i, y_i)\) तथा fitted मानों \(\hat{y}_i = f(x_i)\) के लिए residual error \(e_i = y_i - \hat{y}_i\) होता है। Principle of Least Squares residuals के वर्गों के योग को न्यूनतम करता है:

\[ S = \sum_{i=1}^{n} e_i^2 = \sum_{i=1}^{n} \left[ y_i - f(x_i) \right]^2 \to \text{Minimum} \]

Non-Linear Curves एवं Linearization Transformations का अवलोकन

  • Second-Degree Parabola: \(Y = a + bX + cX^2\) (Parameters \(a, b, c\) में linear; 3 normal equations द्वारा हल किया जाता है)।
  • Exponential Curve: \(Y = a b^X \implies \log Y = \log a + X \log b\) (Common Logarithm द्वारा linearized)।
  • Exponential Curve (Base e): \(Y = a e^{bX} \implies \ln Y = \ln a + b X\) (Natural Logarithm द्वारा linearized)।
  • Power Curve: \(Y = a X^b \implies \log Y = \log a + b \log X\) (Double Logarithm द्वारा linearized)।
  • Logarithmic Curve: \(Y = a + b \log X\) (प्रतिस्थापन \(U = \log X\) द्वारा linearized)।
  • Inverse Curve: \(Y = a + \frac{b}{X}\) (प्रतिस्थापन \(U = \frac{1}{X}\) द्वारा linearized)।

Solution: एक सीधी रेखा परिवर्तन की स्थिर दर (\(\frac{dY}{dX} = b\)) मानती है, जो पठार तथा तीव्र गिरावट को नहीं पकड़ सकती। अतः non-linear curvature को पकड़ने हेतु Second-Degree Parabola (\(Y = a + bX + cX^2\)) या Exponential Decay curve (\(Y = a e^{-bX}\)) का चयन किया जाना चाहिए।

Example 4.1.2 (Residual Sum of Squares Comparison):

Problem: 5 बिंदुओं के data के लिए, straight line fit का residual sum of squares \(SS_{linear} = 45.2\) प्राप्त होता है, जबकि parabola fit का \(SS_{parabola} = 6.8\) प्राप्त होता है। समझाएं कि कौन सा model अधिक उपयुक्त है।

Solution: Principle of Least Squares उस model का चयन करता है जो residual sum of squares को न्यूनतम करता है। चूँकि \(SS_{parabola} = 6.8 \ll SS_{linear} = 45.2\), अतः parabola बहुत अधिक variance की व्याख्या करता है तथा श्रेष्ठतम fit प्रदान करता है।

4.2 Fitting of Straight Line (\(Y = a + bX\))

The simplest linear curve is a straight line represented by \(Y = a + bX\). The Principle of Least Squares determines optimal values for intercept \(a\) and slope \(b\).

Step-by-Step Derivation of Normal Equations

Let the straight line equation be \(Y = a + bX\). The residual sum of squares is:

\[ S = \sum_{i=1}^{n} (y_i - a - b x_i)^2 \]

Differentiating \(S\) partially w.r.t \(a\) and setting to zero:

\[ \frac{\partial S}{\partial a} = -2 \sum (y_i - a - b x_i) = 0 \implies \mathbf{\sum Y = n a + b \sum X} \quad \text{--- Normal Eq (1)} \]

Differentiating \(S\) partially w.r.t \(b\) and setting to zero:

\[ \frac{\partial S}{\partial b} = -2 \sum x_i (y_i - a - b x_i) = 0 \implies \mathbf{\sum XY = a \sum X + b \sum X^2} \quad \text{--- Normal Eq (2)} \]

Solving these two normal equations simultaneously yields parameters \(a\) and \(b\):

\[ b = \frac{n \sum XY - \sum X \sum Y}{n \sum X^2 - (\sum X)^2}, \quad a = \bar{Y} - b \bar{X} \]

Origin Shift Method (\(\sum U = 0\))

If independent values \(X\) are equally spaced, shift origin to mean \(\bar{X}\) by defining \(U = \frac{X - \bar{X}}{h}\) so that \(\sum U = 0\). The normal equations simplify to:

\[ a = \frac{\sum Y}{n} = \bar{Y}, \quad b = \frac{\sum U Y}{\sum U^2} \]

4.2 Straight Line का Fitting (\(Y = a + bX\))

सबसे सरल linear curve सीधी रेखा \(Y = a + bX\) द्वारा व्यक्त की जाती है। Principle of Least Squares intercept \(a\) तथा slope \(b\) के अनुकूलतम मान निर्धारित करता है।

Normal Equations की चरण-दर-चरण व्युत्पत्ति

माना straight line समीकरण \(Y = a + bX\) है। Residual sum of squares:

\[ S = \sum_{i=1}^{n} (y_i - a - b x_i)^2 \]

\(S\) का \(a\) के सापेक्ष आंशिक अवकलन करके शून्य के बराबर रखने पर:

\[ \frac{\partial S}{\partial a} = -2 \sum (y_i - a - b x_i) = 0 \implies \mathbf{\sum Y = n a + b \sum X} \quad \text{--- Normal Eq (1)} \]

\(S\) का \(b\) के सापेक्ष आंशिक अवकलन करके शून्य के बराबर रखने पर:

\[ \frac{\partial S}{\partial b} = -2 \sum x_i (y_i - a - b x_i) = 0 \implies \mathbf{\sum XY = a \sum X + b \sum X^2} \quad \text{--- Normal Eq (2)} \]

इन दोनों normal equations को एक साथ हल करने पर parameters \(a\) तथा \(b\) प्राप्त होते हैं:

\[ b = \frac{n \sum XY - \sum X \sum Y}{n \sum X^2 - (\sum X)^2}, \quad a = \bar{Y} - b \bar{X} \]

Origin Shift विधि (\(\sum U = 0\))

यदि independent मान \(X\) समान अंतराल पर हों, तो origin को mean \(\bar{X}\) पर shift करके \(U = \frac{X - \bar{X}}{h}\) परिभाषित करते हैं ताकि \(\sum U = 0\) हो। Normal equations सरल हो जाती हैं:

\[ a = \frac{\sum Y}{n} = \bar{Y}, \quad b = \frac{\sum U Y}{\sum U^2} \]

4.3 Fitting of Second-Degree Parabola (\(Y = a + bX + cX^2\))

A second-degree parabola (quadratic polynomial) represented by \(Y = a + bX + cX^2\) is used when data exhibits non-monotonic curvature with a single maximum or minimum vertex.

Step-by-Step Derivation of 3 Normal Equations

The residual sum of squares is \(S = \sum_{i=1}^{n} (y_i - a - b x_i - c x_i^2)^2\). Differentiating \(S\) partially w.r.t parameters \(a, b, c\) and setting to zero:

\[ \frac{\partial S}{\partial a} = 0 \implies \mathbf{\sum Y = n a + b \sum X + c \sum X^2} \quad \text{--- Normal Eq (1)} \] \[ \frac{\partial S}{\partial b} = 0 \implies \mathbf{\sum XY = a \sum X + b \sum X^2 + c \sum X^3} \quad \text{--- Normal Eq (2)} \] \[ \frac{\partial S}{\partial c} = 0 \implies \mathbf{\sum X^2 Y = a \sum X^2 + b \sum X^3 + c \sum X^4} \quad \text{--- Normal Eq (3)} \]

Solving this 3-variable linear system determines optimal constants \(a, b, c\).

Parabola Properties & Vertex

  • Vertex (Peak or Trough): Occurs at \(X = -\frac{b}{2c}\).
  • Curvature Direction: If \(c > 0\), parabola opens upward (minimum vertex). If \(c < 0\), parabola opens downward (maximum vertex).

Example 4.3.1 (Fitting Second-Degree Parabola):

Problem: Fit a parabola \(Y = a + bX + cX^2\) to data: \(X = [0, 1, 2, 3, 4]\), \(Y = [1, 1.8, 1.3, 2.5, 6.3]\).

Solution: \(N = 5\). Table totals: \(\sum X = 10, \sum X^2 = 30, \sum X^3 = 100, \sum X^4 = 354\), \(\sum Y = 12.9, \sum XY = 37.9, \sum X^2Y = 135.3\).

Normal equations:

  1. \(5a + 10b + 30c = 12.9\)
  2. \(10a + 30b + 100c = 37.9\)
  3. \(30a + 100b + 354c = 135.3\)

Solving simultaneously yields: \(a = 1.42, b = -1.07, c = 0.55\).

Fitted Parabola: \(\mathbf{Y = 1.42 - 1.07 X + 0.55 X^2}\).

Example 4.3.2 (Parabola via Origin Shift):

Problem: Fit a parabola to data: \(X = [0, 1, 2, 3, 4]\), \(Y = [12, 10, 9, 11, 15]\) using origin shift \(U = X - 2\).

Solution: \(U = [-2, -1, 0, 1, 2] \implies \sum U = 0, \sum U^3 = 0\). \(\sum U^2 = 10, \sum U^4 = 34\). \(\sum Y = 57, \sum U Y = 5, \sum U^2 Y = 105\).

Simplified normal equations:

Eq (2): \(10b = 5 \implies \mathbf{b = 0.5}\).

Eq (1) & (3): \(5a + 10c = 57\) and \(10a + 34c = 105 \implies \mathbf{a = 8.77, c = 1.31}\).

Fitted Equation in \(U\): \(Y = 8.77 + 0.5 U + 1.31 U^2 \implies \mathbf{Y = 13.01 - 4.74 X + 1.31 X^2}\).

4.3 Second-Degree Parabola का Fitting (\(Y = a + bX + cX^2\))

समीकरण \(Y = a + bX + cX^2\) द्वारा व्यक्त second-degree parabola का उपयोग तब किया जाता है जब data एक अधिकतम या न्यूनतम शीर्ष (vertex) के साथ घुमावदार प्रवृत्ति दर्शाता है।

3 Normal Equations की चरण-दर-चरण व्युत्पत्ति

Residual sum of squares \(S = \sum_{i=1}^{n} (y_i - a - b x_i - c x_i^2)^2\) का parameters \(a, b, c\) के सापेक्ष आंशिक अवकलन करके शून्य के बराबर रखने पर:

\[ \frac{\partial S}{\partial a} = 0 \implies \mathbf{\sum Y = n a + b \sum X + c \sum X^2} \quad \text{--- Normal Eq (1)} \] \[ \frac{\partial S}{\partial b} = 0 \implies \mathbf{\sum XY = a \sum X + b \sum X^2 + c \sum X^3} \quad \text{--- Normal Eq (2)} \] \[ \frac{\partial S}{\partial c} = 0 \implies \mathbf{\sum X^2 Y = a \sum X^2 + b \sum X^3 + c \sum X^4} \quad \text{--- Normal Eq (3)} \]

इस 3-चरीय linear समीकरण निकाय को हल करने पर constants \(a, b, c\) प्राप्त होते हैं।

Example 4.3.1 (Fitting Second-Degree Parabola):

Problem: Data \(X = [0, 1, 2, 3, 4]\), \(Y = [1, 1.8, 1.3, 2.5, 6.3]\) के लिए parabola \(Y = a + bX + cX^2\) फिट कीजिए।

Solution: \(N = 5\)। Totals: \(\sum X = 10, \sum X^2 = 30, \sum X^3 = 100, \sum X^4 = 354, \sum Y = 12.9, \sum XY = 37.9, \sum X^2Y = 135.3\)।

Normal equations हल करने पर: \(a = 1.42, b = -1.07, c = 0.55\)।

Fitted Parabola: \(\mathbf{Y = 1.42 - 1.07 X + 0.55 X^2}\)।

Example 4.3.2 (Parabola via Origin Shift):

Problem: Origin shift \(U = X - 2\) का उपयोग करके data \(X = [0, 1, 2, 3, 4]\), \(Y = [12, 10, 9, 11, 15]\) के लिए parabola फिट कीजिए।

Solution: \(U = [-2, -1, 0, 1, 2] \implies \sum U = 0, \sum U^3 = 0\)। Solve: \(b = 0.5, a = 8.77, c = 1.31\)।

Fitted Equation: \(\mathbf{Y = 13.01 - 4.74 X + 1.31 X^2}\)।

4.4 Fitting of Exponential Curves (\(Y = a b^X\) & \(Y = a e^{bX}\))

Exponential curves model biological growth, bacterial propagation, or compound growth where rate of change is proportional to current size.

1. Exponential Curve \(Y = a b^X\) (Logarithmic Transformation)

Taking common logarithm (\(\log_{10}\)) on both sides:

\[ \log Y = \log a + X \log b \implies V = A + B X \]

where \(V = \log Y\), \(A = \log a\), \(B = \log b\). Fitting linear regression of \(V\) on \(X\) gives \(A\) and \(B\). Then original parameters are \(a = 10^A\) and \(b = 10^B\).

2. Exponential Curve \(Y = a e^{bX}\) (Natural Log Transformation)

Taking natural logarithm (\(\ln\)) on both sides:

\[ \ln Y = \ln a + b X \implies V = A + b X \]

where \(V = \ln Y\), \(A = \ln a\). Regressing \(V\) on \(X\) gives slope \(b\) and intercept \(A\). Then \(a = e^A\).

Example 4.4.1 (Fitting Exponential Y = a b^X):

Problem: Fit an exponential curve \(Y = a b^X\) to Bacterial Growth data: \(X = [1, 2, 3, 4, 5]\), \(Y = [32, 47, 65, 92, 132]\).

Solution: Transformed \(V = \log_{10} Y = [1.5051, 1.6721, 1.8129, 1.9638, 2.1206]\).

\(N = 5, \sum X = 15, \sum X^2 = 55, \sum V = 9.0745, \sum (XV) = 28.7495\).

4.4 Exponential Curves का Fitting (\(Y = a b^X\) & \(Y = a e^{bX}\))

Exponential curves जैविक वृद्धि, जीवाणु वृद्धि, या चक्रवृद्धि वृद्धि को मॉडल करती हैं जहाँ परिवर्तन की दर वर्तमान आकार के समानुपाती होती है।

1. Exponential Curve \(Y = a b^X\) (Logarithmic Transformation)

दोनों पक्षों का common logarithm (\(\log_{10}\)) लेने पर:

\[ \log Y = \log a + X \log b \implies V = A + B X \]

जहाँ \(V = \log Y, A = \log a, B = \log b\)। \(V\) का \(X\) पर linear regression फिट करके \(A\) तथा \(B\) प्राप्त होते हैं। मूल parameters: \(a = 10^A, b = 10^B\)।

2. Exponential Curve \(Y = a e^{bX}\) (Natural Log Transformation)

दोनों पक्षों का natural logarithm (\(\ln\)) लेने पर:

\[ \ln Y = \ln a + b X \implies V = A + b X \]

जहाँ \(V = \ln Y, A = \ln a\)। \(V\) का \(X\) पर regression फिट करके \(b\) तथा \(A\) प्राप्त होते हैं। \(a = e^A\)।

Example 4.4.1 (Fitting Exponential Y = a b^X):

Problem: Bacterial Growth data \(X = [1, 2, 3, 4, 5]\), \(Y = [32, 47, 65, 92, 132]\) के लिए exponential curve \(Y = a b^X\) फिट कीजिए।

Solution: Transformed \(V = \log_{10} Y = [1.5051, 1.6721, 1.8129, 1.9638, 2.1206]\)।

Solve: \(B = 0.1526, A = 1.3571 \implies a = 10^{1.3571} = 22.76, b = 10^{0.1526} = 1.421\)।

Fitted Exponential Curve: \(\mathbf{Y = 22.76 (1.421)^X}\)।

Example 4.4.2 (Fitting Exponential Y = a e^{bX}):

Problem: Crop Biomass data \(X = [0, 2, 4, 6, 8]\), \(Y = [5.0, 8.2, 13.5, 22.2, 36.6]\) के लिए \(Y = a e^{bX}\) फिट कीजिए।

Solution: \(V = \ln Y = [1.6094, 2.1041, 2.6027, 3.1001, 3.5999]\)। Solve: \(b = 0.3737, A = 1.1084 \implies a = 3.03\)।

Fitted Curve: \(\mathbf{Y = 3.03 e^{0.3737 X}}\)।

4.5 Fitting of Power Curve (\(Y = a X^b\))

Power curves model scale-invariant physical and biological relationships such as tree diameter vs timber volume or body mass vs metabolic rate.

Double Logarithmic Transformation

Taking common logarithm (\(\log_{10}\)) on both sides of \(Y = a X^b\):

\[ \log Y = \log a + b \log X \implies V = A + b U \]
Symbol Guide:
  • \(V = \log_{10} Y\) (log-transformed dependent variable).
  • \(U = \log_{10} X\) (log-transformed independent variable).
  • \(A = \log_{10} a \implies a = 10^A\).
  • \(b\) = Power exponent (slope in log-log space).

Example 4.5.1 (Fitting Power Curve Y = a X^b):

Problem: Fit a power curve \(Y = a X^b\) to Tree Diameter (\(X\) in cm) vs Timber Volume (\(Y\) in m³): \(X = [2, 3, 4, 5, 6]\), \(Y = [8.2, 18.1, 31.8, 49.5, 71.2]\).

Solution:

\(U = \log_{10} X = [0.3010, 0.4771, 0.6021, 0.6990, 0.7782] \implies \sum U = 2.8574\).

\(V = \log_{10} Y = [0.9138, 1.2577, 1.5024, 1.6946, 1.8525] \implies \sum V = 7.2210\).

Calculating least squares slope \(b\) in \((U, V)\) space: \(b \approx 1.96\).

\(A = \bar{V} - b \bar{U} = 1.4442 - 1.96(0.5715) = 0.3241 \implies a = 10^{0.3241} = 2.11\).

Fitted Power Curve: \(\mathbf{Y = 2.11 X^{1.96}}\).

Example 4.5.2 (Power Curve Application):

Problem: If a fitted power curve relating Water Discharge (\(X\)) to Energy Output (\(Y\)) is \(Y = 1.5 X^{1.5}\), predict \(Y\) when \(X = 9\).

Solution: Substitute \(X = 9\):

\[ Y = 1.5 (9)^{1.5} = 1.5 (\sqrt{9})^3 = 1.5 (27) = \mathbf{40.5 \text{ units}} \]

4.6 Logarithmic & Inverse Transformations (\(Y = a + b \log X\) & \(Y = a + \frac{b}{X}\))

1. Logarithmic Curve (\(Y = a + b \log X\))

Substitute \(U = \log_{10} X\). The equation becomes \(Y = a + b U\). Regressing \(Y\) on \(U\) using standard linear least squares gives parameters \(a\) and \(b\).

2. Inverse Curve (\(Y = a + \frac{b}{X}\))

Substitute \(U = \frac{1}{X}\). The equation becomes \(Y = a + b U\). Regressing \(Y\) on \(U\) gives intercept \(a\) and slope \(b\). As \(X \to \infty\), \(Y\) approaches asymptote \(a\).

Example 4.6.1 (Fitting Logarithmic Curve):

Problem: Fit \(Y = a + b \log_{10} X\) to Root Depth (\(Y\) in cm) vs Plant Age (\(X\) in days): \(X = [10, 20, 30, 40, 50]\), \(Y = [5, 8, 10, 11.5, 12.6]\).

Solution: \(U = \log_{10} X = [1.000, 1.301, 1.477, 1.602, 1.699] \implies \bar{U} = 1.4158\), \(\bar{Y} = 9.42\).

Linear regression of \(Y\) on \(U\) yields \(b = 10.87, a = -5.97\).

Fitted Curve: \(\mathbf{Y = -5.97 + 10.87 \log_{10} X}\).

Example 4.6.2 (Fitting Inverse Curve):

Problem: Fit \(Y = a + \frac{b}{X}\) to Fertilizer Efficiency data: \(X = [1, 2, 4, 5, 10]\), \(Y = [12, 7, 4.5, 4, 3]\).

Solution: \(U = \frac{1}{X} = [1.0, 0.5, 0.25, 0.2, 0.1] \implies \bar{U} = 0.41\), \(\bar{Y} = 6.1\).

Linear regression of \(Y\) on \(U\) yields \(b = 10.0, a = 2.0\).

Fitted Inverse Curve: \(\mathbf{Y = 2.0 + \frac{10.0}{X}}\). Asymptote as \(X \to \infty\) is \(Y = 2.0\).

4.6 Logarithmic एवं Inverse Transformations (\(Y = a + b \log X\) & \(Y = a + \frac{b}{X}\))

1. Logarithmic Curve (\(Y = a + b \log X\))

प्रतिस्थापन \(U = \log_{10} X\) करने पर समीकरण \(Y = a + b U\) बन जाता है। Standard linear least squares द्वारा \(Y\) का \(U\) पर regression फिट करके parameters \(a\) तथा \(b\) प्राप्त होते हैं।

2. Inverse Curve (\(Y = a + \frac{b}{X}\))

प्रतिस्थापन \(U = \frac{1}{X}\) करने पर समीकरण \(Y = a + b U\) बन जाता है। \(Y\) का \(U\) पर regression फिट करके intercept \(a\) तथा slope \(b\) प्राप्त होते हैं। जब \(X \to \infty\), \(Y\) अनंतस्पर्शी (asymptote) \(a\) की ओर प्रवृत्त होता है।

Example 4.6.1 (Fitting Logarithmic Curve):

Problem: Root Depth (\(Y\)) बनाम Plant Age (\(X\)) data \(X = [10, 20, 30, 40, 50]\), \(Y = [5, 8, 10, 11.5, 12.6]\) के लिए \(Y = a + b \log_{10} X\) फिट कीजिए।

Solution: \(U = \log_{10} X\)। Regression fit: \(b = 10.87, a = -5.97\)।

Fitted Curve: \(\mathbf{Y = -5.97 + 10.87 \log_{10} X}\)।

Example 4.6.2 (Fitting Inverse Curve):

Problem: Fertilizer Efficiency data \(X = [1, 2, 4, 5, 10]\), \(Y = [12, 7, 4.5, 4, 3]\) के लिए \(Y = a + \frac{b}{X}\) फिट कीजिए।

Solution: \(U = \frac{1}{X}\)। Regression fit: \(b = 10.0, a = 2.0\)।

Fitted Inverse Curve: \(\mathbf{Y = 2.0 + \frac{10.0}{X}}\)।

4.7 Summary & Comparison of Non-Linear Curves

Selecting the most appropriate non-linear curve requires evaluating mathematical properties, parameter count, and goodness of fit.

Straight Line \(Y = a + bX\) None (Linear in parameters) \(Y = a + bX\) Constant rate of change
Second-Degree Parabola \(Y = a + bX + cX^2\) None (Polynomial in X) \(Y = a + bX + cX^2\) U-shaped or inverted U-shaped trends
Exponential (b^X) \(Y = a b^X\) \(V = \log_{10} Y, A = \log a, B = \log b\) \(V = A + B X\) Constant percentage growth/decay
Exponential (e^{bX}) \(Y = a e^{bX}\) \(V = \ln Y, A = \ln a\) \(V = A + b X\) Continuous biological growth

Example 4.7.1 (Goodness of Fit R^2 Evaluation):

Problem: For a dataset, fitting a straight line gives \(R^2 = 0.72\), while a parabola gives \(R^2 = 0.94\). Explain which model explains more variance.

Solution: \(R^2\) represents the proportion of total variance explained by the model. The parabola explains 94% of total variance compared to only 72% by the straight line, confirming the parabola is a superior fit.

Example 4.7.2 (Model Selection Principle):

Problem: Explain why a higher-degree polynomial (e.g. 4th degree) may yield \(R^2 = 0.99\) but be inferior to a 2nd degree parabola with \(R^2 = 0.96\).

Solution: High-degree polynomials suffer from overfitting and extreme edge oscillations (Runge's phenomenon). A 2nd degree parabola is more parsimonious, robust, and physically interpretable.

📝 Subjective Questions — 30 Questions

Q1. Explain the Principle of Least Squares. Derive the normal equations for fitting a straight line Y = a + bX.
Solution:

Principle of Least Squares minimizes the sum of squared vertical residuals S = Σ (y_i - a - b x_i)². Differentiating S partially w.r.t 'a' and 'b': ∂S/∂a = -2 Σ (y_i - a - b x_i) = 0 ⇒ Σ Y = n a + b Σ X. ∂S/∂b = -2 Σ x_i (y_i - a - b x_i) = 0 ⇒ Σ XY = a Σ X + b Σ X². Solving these two normal equations yields optimal parameters 'a' and 'b'.

Q2. Derive the 3 normal equations for fitting a second-degree parabola Y = a + bX + cX².
Solution:

Residual sum of squares S = Σ (y_i - a - b x_i - c x_i²)². Differentiating S partially w.r.t 'a', 'b', and 'c': 1) ∂S/∂a = 0 ⇒ Σ Y = n a + b Σ X + c Σ X². 2) ∂S/∂b = 0 ⇒ Σ XY = a Σ X + b Σ X² + c Σ X³. 3) ∂S/∂c = 0 ⇒ Σ X² Y = a Σ X² + b Σ X³ + c Σ X⁴. Solving this system of 3 linear equations gives optimal values for a, b, and c.

Q3. Explain how to fit an exponential curve Y = a b^X using logarithmic transformation.
Solution:

Take common log of Y = a b^X: log Y = log a + X log b. Let V = log Y, A = log a, B = log b. This gives linear form V = A + B X. Apply least squares to compute A and B: B = [n Σ (X V) - Σ X Σ V] / [n Σ X² - (Σ X)²] and A = V̄ - B X̄. Finally obtain original parameters: a = antilog(A) = 10^A and b = antilog(B) = 10^B.

Q4. Explain how to fit an exponential curve Y = a e^{bX} using natural logarithms.
Solution:

Take natural log of Y = a e^{bX}: ln Y = ln a + b X. Let V = ln Y and A = ln a. This yields linear equation V = A + b X. Solve normal equations: Σ V = n A + b Σ X and Σ (X V) = A Σ X + b Σ X². Compute b = [n Σ (X V) - Σ X Σ V] / [n Σ X² - (Σ X)²] and A = V̄ - b X̄. Then a = e^A.

Q5. Explain how to fit a power curve Y = a X^b using double logarithmic transformation.
Solution:

Take common log of Y = a X^b: log Y = log a + b log X. Let V = log Y, U = log X, A = log a. This gives linear equation V = A + b U. Fit linear regression of V on U by least squares: b = [n Σ (U V) - Σ U Σ V] / [n Σ U² - (Σ U)²] and A = V̄ - b Ū. Convert back: a = antilog(A) = 10^A.

Q6. Explain the fitting of Logarithmic Curve Y = a + b log X and Inverse Curve Y = a + b/X.
Solution:

1) Logarithmic Curve Y = a + b log X: Substitute U = log X to get Y = a + b U. Regress Y on U using standard linear least squares. 2) Inverse Curve Y = a + b/X: Substitute U = 1/X to get Y = a + b U. Regress Y on U using standard linear least squares.

Q7. Compare Straight Line, Second-Degree Parabola, Exponential Curve, and Power Curve in terms of equation, linearized form, and application.
Solution:

1) Straight Line Y = a + bX: Linear in itself; constant rate of change. 2) Parabola Y = a + bX + cX²: Linear in parameters a,b,c; models U-shaped/inverted U-shaped curvature. 3) Exponential Y = a b^X: Linearized as log Y = log a + X log b; models constant percentage growth. 4) Power Y = a X^b: Linearized as log Y = log a + b log X; models scale-invariant power-law relationships.

Q8. Define Coefficient of Determination R² and explain its role in evaluating non-linear curve fit.
Solution:

R² = Explained Variance / Total Variance = 1 - [Σ (Y_i - Ŷ_i)² / Σ (Y_i - Ȳ)²]. R² measures the proportion of total variation in Y explained by the fitted model. R² = 1 indicates perfect fit; R² = 0 indicates model explains no variation.

Q9. Fit a second-degree parabola Y = a + bX + cX² to data: X = [0, 1, 2, 3, 4], Y = [1, 1.8, 1.3, 2.5, 6.3].
Solution:

Totals for N = 5: Σ X = 10, Σ X² = 30, Σ X³ = 100, Σ X⁴ = 354, Σ Y = 12.9, Σ XY = 37.9, Σ X²Y = 135.3. Normal equations: 1) 5a + 10b + 30c = 12.9. 2) 10a + 30b + 100c = 37.9. 3) 30a + 100b + 354c = 135.3. Solving gives a = 1.42, b = -1.07, c = 0.55. Equation: Y = 1.42 - 1.07 X + 0.55 X².

Q10. Fit an exponential curve Y = a b^X to data: X = [1, 2, 3, 4, 5], Y = [32, 47, 65, 92, 132].
Solution:

Take log10 Y: V = [1.5051, 1.6721, 1.8129, 1.9638, 2.1206]. Totals: N = 5, Σ X = 15, Σ X² = 55, Σ V = 9.0745, Σ (XV) = 28.7495. B = [5(28.7495) - 15(9.0745)] / [5(55) - 225] = [143.7475 - 136.1175] / 50 = 7.63 / 50 = 0.1526. A = (9.0745 / 5) - 0.1526(3) = 1.8149 - 0.4578 = 1.3571. Parameters: a = 10^{1.3571} = 22.76, b = 10^{0.1526} = 1.421. Equation: Y = 22.76 (1.421)^X.
