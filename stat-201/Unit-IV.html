4.1 Plane of Regression: Regression in Three Variables

In agricultural, biological, and economic research, a dependent response variable (\(X_1\), e.g. Crop Yield) is simultaneously influenced by two or more predictor variables (\(X_2\), e.g. Rainfall, and \(X_3\), e.g. Fertilizer Dose). Analyzing such data requires Multivariate Data Analysis. For three variables \((X_1, X_2, X_3)\), the linear relationship is represented by a 3-dimensional Plane of Regression.

Plane of Regression Equation

The equation of the plane of regression of \(X_1\) on \(X_2\) and \(X_3\) measured from their respective sample means \(\bar{X}_1, \bar{X}_2, \bar{X}_3\) (where \(x_i = X_i - \bar{X}_i\)) is expressed as:

\[ (X_1 - \bar{X}_1) = b_{12.3} (X_2 - \bar{X}_2) + b_{13.2} (X_3 - \bar{X}_3) \implies x_1 = b_{12.3} x_2 + b_{13.2} x_3 \]

In uncentered absolute terms: \(X_1 = a_{1.23} + b_{12.3} X_2 + b_{13.2} X_3\), where \(a_{1.23} = \bar{X}_1 - b_{12.3} \bar{X}_2 - b_{13.2} \bar{X}_3\).

Symbol & Parameter Guide:
  • \(X_1\): Primary dependent (response) variable.
  • \(X_2, X_3\): Independent (predictor / explanatory) variables.
  • \(b_{12.3}\): Partial regression coefficient of \(X_1\) on \(X_2\), holding \(X_3\) constant.
  • \(b_{13.2}\): Partial regression coefficient of \(X_1\) on \(X_3\), holding \(X_2\) constant.

Derivation of Partial Regression Coefficients via Least Squares

The residual sum of squares is \(S = \sum_{i=1}^{n} (x_{1i} - b_{12.3} x_{2i} - b_{13.2} x_{3i})^2\). Differentiating \(S\) partially w.r.t \(b_{12.3}\) and \(b_{13.2}\) and setting to zero yields the two Normal Equations:

\[ \sum x_1 x_2 = b_{12.3} \sum x_2^2 + b_{13.2} \sum x_2 x_3 \quad \text{--- Normal Eq (1)} \] \[ \sum x_1 x_3 = b_{12.3} \sum x_2 x_3 + b_{13.2} \sum x_3^2 \quad \text{--- Normal Eq (2)} \]

Expressing in terms of standard deviations \(\sigma_1, \sigma_2, \sigma_3\) and zero-order correlations \(r_{12}, r_{13}, r_{23}\):

\[ b_{12.3} = \frac{\sigma_1}{\sigma_2} \left( \frac{r_{12} - r_{13} r_{23}}{1 - r_{23}^2} \right), \quad b_{13.2} = \frac{\sigma_1}{\sigma_3} \left( \frac{r_{13} - r_{12} r_{23}}{1 - r_{23}^2} \right) \]

Example 4.1.1 (Calculating Partial Regression Coefficients):

Problem: Given \(\sigma_1 = 3, \sigma_2 = 4, \sigma_3 = 5\) and zero-order correlations \(r_{12} = 0.8, r_{13} = 0.6, r_{23} = 0.5\), calculate \(b_{12.3}\) and \(b_{13.2}\).

Solution:

\[ b_{12.3} = \frac{3}{4} \left[ \frac{0.8 - (0.6)(0.5)}{1 - (0.5)^2} \right] = 0.75 \left[ \frac{0.8 - 0.30}{1 - 0.25} \right] = 0.75 \left[ \frac{0.50}{0.75} \right] = \mathbf{0.50} \] \[ b_{13.2} = \frac{3}{5} \left[ \frac{0.6 - (0.8)(0.5)}{1 - (0.5)^2} \right] = 0.60 \left[ \frac{0.6 - 0.40}{0.75} \right] = 0.60 \left[ \frac{0.20}{0.75} \right] = \mathbf{0.16} \]

Example 4.1.2 (Fitting Plane of Regression Equation):

Problem: Using the coefficients from Example 4.1.1 and sample means \(\bar{X}_1 = 20, \bar{X}_2 = 30, \bar{X}_3 = 40\), state the plane of regression equation and predict \(X_1\) when \(X_2 = 32\) and \(X_3 = 45\).

Solution: Equation: \((X_1 - 20) = 0.50 (X_2 - 30) + 0.16 (X_3 - 40) \implies \mathbf{X_1 = -1.4 + 0.50 X_2 + 0.16 X_3}\).

For \(X_2 = 32, X_3 = 45\): \(X_1 = -1.4 + 0.50(32) + 0.16(45) = -1.4 + 16.0 + 7.2 = \mathbf{21.8}\).

4.1 Plane of Regression: तीन Variables का Regression

कृषि, जैविक, तथा आर्थिक अनुसंधानों में, एक dependent response variable (\(X_1\), जैसे Crop Yield) एक साथ दो या अधिक predictor variables (\(X_2\), जैसे Rainfall, तथा \(X_3\), जैसे Fertilizer Dose) से प्रभावित होता है। ऐसे data का विश्लेषण Multivariate Data Analysis कहलाता है। तीन variables \((X_1, X_2, X_3)\) के लिए, linear संबंध 3-dimensional Plane of Regression द्वारा व्यक्त किया जाता है।

Plane of Regression का समीकरण

सैंपल means \(\bar{X}_1, \bar{X}_2, \bar{X}_3\) से मापे गए \(X_1\) का \(X_2\) तथा \(X_3\) पर plane of regression का समीकरण निम्न रूप में व्यक्त किया जाता है (जहाँ \(x_i = X_i - \bar{X}_i\)):

\[ (X_1 - \bar{X}_1) = b_{12.3} (X_2 - \bar{X}_2) + b_{13.2} (X_3 - \bar{X}_3) \implies x_1 = b_{12.3} x_2 + b_{13.2} x_3 \]

अकेंद्रित रूप में: \(X_1 = a_{1.23} + b_{12.3} X_2 + b_{13.2} X_3\), जहाँ \(a_{1.23} = \bar{X}_1 - b_{12.3} \bar{X}_2 - b_{13.2} \bar{X}_3\)।

Symbol Guide:
  • \(X_1\): मुख्य dependent variable।
  • \(X_2, X_3\): Independent (predictor) variables।
  • \(b_{12.3}\): \(X_3\) को स्थिर रखते हुए \(X_1\) का \(X_2\) पर partial regression coefficient।
  • \(b_{13.2}\): \(X_2\) को स्थिर रखते हुए \(X_1\) का \(X_3\) पर partial regression coefficient।

Least Squares द्वारा Partial Regression Coefficients की व्युत्पत्ति

Residual sum of squares \(S = \sum_{i=1}^{n} (x_{1i} - b_{12.3} x_{2i} - b_{13.2} x_{3i})^2\) का \(b_{12.3}\) तथा \(b_{13.2}\) के सापेक्ष आंशिक अवकलन करके शून्य के बराबर रखने पर दो Normal Equations प्राप्त होती हैं:

\[ \sum x_1 x_2 = b_{12.3} \sum x_2^2 + b_{13.2} \sum x_2 x_3 \quad \text{--- Normal Eq (1)} \] \[ \sum x_1 x_3 = b_{12.3} \sum x_2 x_3 + b_{13.2} \sum x_3^2 \quad \text{--- Normal Eq (2)} \]

Standard deviations \(\sigma_1, \sigma_2, \sigma_3\) तथा zero-order correlations \(r_{12}, r_{13}, r_{23}\) के पदों में:

\[ b_{12.3} = \frac{\sigma_1}{\sigma_2} \left( \frac{r_{12} - r_{13} r_{23}}{1 - r_{23}^2} \right), \quad b_{13.2} = \frac{\sigma_1}{\sigma_3} \left( \frac{r_{13} - r_{12} r_{23}}{1 - r_{23}^2} \right) \]

Example 4.1.1 (Calculating Partial Regression Coefficients):

Problem: \(\sigma_1 = 3, \sigma_2 = 4, \sigma_3 = 5\) तथा correlations \(r_{12} = 0.8, r_{13} = 0.6, r_{23} = 0.5\) दिए होने पर \(b_{12.3}\) तथा \(b_{13.2}\) की गणना कीजिए।

Solution: Solve: \(b_{12.3} = \mathbf{0.50}\), \(b_{13.2} = \mathbf{0.16}\)।

Example 4.1.2 (Fitting Plane of Regression Equation):

Problem: Example 4.1.1 के coefficients तथा \(\bar{X}_1 = 20, \bar{X}_2 = 30, \bar{X}_3 = 40\) का उपयोग करके plane of regression का समीकरण ज्ञात कीजिए तथा \(X_2 = 32, X_3 = 45\) होने पर \(X_1\) का अनुमान लगाइए।

Solution: Equation: \(\mathbf{X_1 = -1.4 + 0.50 X_2 + 0.16 X_3}\)। \(X_1 = -1.4 + 0.50(32) + 0.16(45) = \mathbf{21.8}\)।

4.2 Properties of Residuals: Mean, Variance & Distribution

The residual \(e_{1.23}\) is the difference between observed value \(X_1\) and estimated value \(\hat{X}_1\) on the plane of regression: \(e_{1.23} = X_1 - \hat{X}_1 = x_1 - b_{12.3} x_2 - b_{13.2} x_3\).

Three Fundamental Properties of Residuals

  1. Property 1 (Zero Mean): The mean of the residuals is identically zero: \(\bar{e}_{1.23} = E[e_{1.23}] = 0\).
  2. Property 2 (Orthogonality / Zero Correlation): The residual \(e_{1.23}\) is completely uncorrelated with independent predictor variables \(X_2\) and \(X_3\): \[ \sum_{i=1}^{n} e_{1.23} x_2 = 0 \quad \text{and} \quad \sum_{i=1}^{n} e_{1.23} x_3 = 0 \]
  3. Property 3 (Normal Distribution): Under the assumption of multivariate normality of \((X_1, X_2, X_3)\), the residual \(e_{1.23}\) follows a univariate Normal Distribution with mean 0 and variance \(\sigma_{1.23}^2\): \[ e_{1.23} \sim N(0, \sigma_{1.23}^2) \]

Example 4.2.1 (Verification of Residual Mean):

Problem: For a trivariate dataset of 5 observations, observed values are \(X_1 = [10, 15, 20, 25, 30]\) and fitted values are \(\hat{X}_1 = [10.2, 14.8, 19.9, 25.3, 29.8]\). Verify that residual mean is zero.

Solution: Residuals \(e = X_1 - \hat{X}_1 = [-0.2, +0.2, +0.1, -0.3, +0.2]\). \(\sum e = -0.2 + 0.2 + 0.1 - 0.3 + 0.2 = 0.0 \implies \bar{e} = 0.0\).

Example 4.2.2 (Residual Orthogonality Property):

Problem: Explain why \(\sum e_{1.23} \hat{X}_1 = 0\) and \(\sum e_{1.23} X_1 = \sum e_{1.23}^2\).

Solution: Since \(\hat{X}_1 = a + b_{12.3} X_2 + b_{13.2} X_3\), multiplying by \(e_{1.23}\) and summing gives \(\sum e \hat{X}_1 = a \sum e + b_{12.3} \sum e X_2 + b_{13.2} \sum e X_3 = 0 + 0 + 0 = 0\). Further, \(\sum e X_1 = \sum e (\hat{X}_1 + e) = \sum e \hat{X}_1 + \sum e^2 = 0 + \sum e^2 = \sum e_{1.23}^2\).

4.2 Residuals के गुणधर्म: Mean, Variance एवं Distribution

Residual \(e_{1.23}\) observed मान \(X_1\) तथा plane of regression पर estimated मान \(\hat{X}_1\) के बीच का अंतर होता है: \(e_{1.23} = X_1 - \hat{X}_1 = x_1 - b_{12.3} x_2 - b_{13.2} x_3\)।

Residuals के तीन आधारभूत गुणधर्म

  1. Property 1 (Zero Mean): Residuals का माध्य हमेशा शून्य होता है: \(\bar{e}_{1.23} = E[e_{1.23}] = 0\)।
  2. Property 2 (Orthogonality / Zero Correlation): Residual \(e_{1.23}\) स्वतंत्रpredictor variables \(X_2\) तथा \(X_3\) के साथ पूरी तरह से uncorrelated होता है: \[ \sum_{i=1}^{n} e_{1.23} x_2 = 0 \quad \text{तथा} \quad \sum_{i=1}^{n} e_{1.23} x_3 = 0 \]
  3. Property 3 (Normal Distribution): \((X_1, X_2, X_3)\) की multivariate normality की अवधारणा के तहत, residual \(e_{1.23}\) माध्य 0 तथा variance \(\sigma_{1.23}^2\) के साथ Normal Distribution का पालन करता है: \[ e_{1.23} \sim N(0, \sigma_{1.23}^2) \]

Example 4.2.1 (Verification of Residual Mean):

Problem: Observed \(X_1 = [10, 15, 20, 25, 30]\) तथा fitted \(\hat{X}_1 = [10.2, 14.8, 19.9, 25.3, 29.8]\) हेतु सिद्ध कीजिए कि residual mean शून्य है।

Solution: Residuals \(e = [-0.2, +0.2, +0.1, -0.3, +0.2] \implies \sum e = 0.0 \implies \bar{e} = 0.0\)।

Example 4.2.2 (Residual Orthogonality Property):

Problem: समझाएं कि \(\sum e_{1.23} \hat{X}_1 = 0\) तथा \(\sum e_{1.23} X_1 = \sum e_{1.23}^2\) क्यों होता है।

Solution: \(\hat{X}_1\) में \(X_2, X_3\) की उपस्थिति के कारण Orthogonality property से \(\sum e \hat{X}_1 = 0\)। तथा \(\sum e X_1 = \sum e (\hat{X}_1 + e) = 0 + \sum e^2 = \sum e_{1.23}^2\)।

4.3 Variance of the Residual (\(\sigma_{1.23}^2\))

The variance of the residual \(\sigma_{1.23}^2\) measures the unexplained scatter or error variance of \(X_1\) around the plane of regression.

Derivation of Residual Variance Formula

By definition, residual variance is \(\sigma_{1.23}^2 = \frac{1}{n} \sum e_{1.23}^2\). Using Property 2 (\(\sum e x_1 = \sum e^2\)):

\[ \sigma_{1.23}^2 = \frac{1}{n} \sum x_1 (x_1 - b_{12.3} x_2 - b_{13.2} x_3) = \sigma_1^2 - b_{12.3} \text{Cov}(X_1, X_2) - b_{13.2} \text{Cov}(X_1, X_3) \]

Substituting expressions for \(b_{12.3}\) and \(b_{13.2}\) in terms of zero-order correlations:

\[ \sigma_{1.23}^2 = \sigma_1^2 \left[ 1 - \frac{r_{12}^2 + r_{13}^2 - 2 r_{12} r_{13} r_{23}}{1 - r_{23}^2} \right] = \sigma_1^2 (1 - R_{1.23}^2) \]

In determinant form using correlation matrix determinant \(w\): \(\sigma_{1.23}^2 = \sigma_1^2 \frac{w}{w_{11}}\).

Example 4.3.1 (Calculating Residual Variance):

Problem: Given \(\sigma_1 = 6\) and Multiple Correlation Coefficient \(R_{1.23} = 0.80\), calculate the residual variance \(\sigma_{1.23}^2\).

Solution:

\[ \sigma_{1.23}^2 = \sigma_1^2 (1 - R_{1.23}^2) = (6)^2 (1 - 0.80^2) = 36 (1 - 0.64) = 36 (0.36) = \mathbf{12.96} \]

Example 4.3.2 (Residual Standard Error):

Problem: Calculate the Residual Standard Error \(\sigma_{1.23}\) for Example 4.3.1.

Solution: \(\sigma_{1.23} = \sqrt{12.96} = \mathbf{3.60}\).

4.3 Residual की Variance (\(\sigma_{1.23}^2\))

Residual variance \(\sigma_{1.23}^2\) plane of regression के चारों ओर \(X_1\) के व्याख्याहीन (unexplained) बिखराव या त्रुटि variance को मापता है।

Residual Variance सूत्र की व्युत्पत्ति

परिभाषा के अनुसार, \(\sigma_{1.23}^2 = \frac{1}{n} \sum e_{1.23}^2\)। Property 2 (\(\sum e x_1 = \sum e^2\)) का उपयोग करने पर:

\[ \sigma_{1.23}^2 = \sigma_1^2 (1 - R_{1.23}^2) \]

Correlation matrix determinant \(w\) का उपयोग करते हुए: \(\sigma_{1.23}^2 = \sigma_1^2 \frac{w}{w_{11}}\)।

Example 4.3.1 (Calculating Residual Variance):

Problem: \(\sigma_1 = 6\) तथा Multiple Correlation Coefficient \(R_{1.23} = 0.80\) दिए होने पर residual variance \(\sigma_{1.23}^2\) की गणना कीजिए।

Solution: \(\sigma_{1.23}^2 = (6)^2 (1 - 0.80^2) = 36 (0.36) = \mathbf{12.96}\)।

Example 4.3.2 (Residual Standard Error):

Problem: Example 4.3.1 हेतु Residual Standard Error \(\sigma_{1.23}\) की गणना कीजिए।

Solution: \(\sigma_{1.23} = \sqrt{12.96} = \mathbf{3.60}\)।

4.4 Multiple Correlation Coefficient (\(R_{1.23}\)) & Its Properties

The Multiple Correlation Coefficient \(R_{1.23}\) measures the degree of joint linear association between the dependent variable \(X_1\) and the combined linear estimate \(\hat{X}_1\) provided by independent variables \(X_2\) and \(X_3\).

Formula for Multiple Correlation Coefficient

\[ R_{1.23} = \sqrt{\frac{r_{12}^2 + r_{13}^2 - 2 r_{12} r_{13} r_{23}}{1 - r_{23}^2}} \]

4 Fundamental Properties of Multiple Correlation Coefficient

  1. Property 1 (Range): \(R_{1.23}\) is always non-negative and bounded between 0 and 1: \(0 \le R_{1.23} \le 1\).
  2. Property 2 (Dominance over Zero-Order Correlations): \(R_{1.23}\) is always greater than or equal to absolute simple correlation coefficients: \(R_{1.23} \ge |r_{12}|\) and \(R_{1.23} \ge |r_{13}|\).
  3. Property 3 (Perfect Fit): If \(R_{1.23} = 1\), all observed data points lie exactly on the plane of regression, and residual variance \(\sigma_{1.23}^2 = 0\).
  4. Property 4 (Zero Association): If \(R_{1.23} = 0\), then \(r_{12} = 0\) and \(r_{13} = 0\), meaning \(X_1\) is completely uncorrelated with both \(X_2\) and \(X_3\).

Example 4.4.1 (Calculating Multiple Correlation Coefficient):

Problem: Given zero-order correlations \(r_{12} = 0.6, r_{13} = 0.7, r_{23} = 0.5\), calculate \(R_{1.23}\).

Solution:

\[ R_{1.23}^2 = \frac{0.6^2 + 0.7^2 - 2(0.6)(0.7)(0.5)}{1 - 0.5^2} = \frac{0.36 + 0.49 - 0.42}{1 - 0.25} = \frac{0.43}{0.75} = 0.5733 \] \[ R_{1.23} = \sqrt{0.5733} = \mathbf{0.757} \]

Example 4.4.2 (Symmetric Correlation Case):

Problem: If all zero-order correlations are equal to \(r = 0.60\), calculate \(R_{1.23}\).

Solution: Using symmetric formula \(R_{1.23}^2 = \frac{2 r^2}{1 + r} = \frac{2(0.36)}{1.6} = \frac{0.72}{1.6} = 0.45 \implies R_{1.23} = \sqrt{0.45} = \mathbf{0.671}\).

4.4 Multiple Correlation Coefficient (\(R_{1.23}\)) एवं इसके गुणधर्म

Multiple Correlation Coefficient \(R_{1.23}\) dependent variable \(X_1\) तथा स्वतंत्र predictor variables \(X_2, X_3\) द्वारा प्रदान किए गए संयुक्त रैखिक अनुमान \(\hat{X}_1\) के बीच की घनिष्ठता को मापता है।

Multiple Correlation Coefficient का सूत्र

\[ R_{1.23} = \sqrt{\frac{r_{12}^2 + r_{13}^2 - 2 r_{12} r_{13} r_{23}}{1 - r_{23}^2}} \]

Multiple Correlation Coefficient के 4 आधारभूत गुणधर्म

  1. Property 1 (Range): \(R_{1.23}\) हमेशा धनात्मक तथा 0 से 1 के बीच होता है: \(0 \le R_{1.23} \le 1\)।
  2. Property 2 (Dominance over Zero-Order Correlations): \(R_{1.23}\) हमेशा किसी भी simple correlation से बड़ा या बराबर होता है: \(R_{1.23} \ge |r_{12}|\) तथा \(R_{1.23} \ge |r_{13}|\)।
  3. Property 3 (Perfect Fit): यदि \(R_{1.23} = 1\), तो सभी बिंदु plane of regression पर स्थित होते हैं, तथा residual variance \(\sigma_{1.23}^2 = 0\)।
  4. Property 4 (Zero Association): यदि \(R_{1.23} = 0\), तो \(r_{12} = 0\) तथा \(r_{13} = 0\)।

Example 4.4.1 (Calculating Multiple Correlation Coefficient):

Problem: Correlations \(r_{12} = 0.6, r_{13} = 0.7, r_{23} = 0.5\) के लिए \(R_{1.23}\) की गणना कीजिए।

Solution: \(R_{1.23}^2 = \frac{0.43}{0.75} = 0.5733 \implies R_{1.23} = \mathbf{0.757}\)।

Example 4.4.2 (Symmetric Correlation Case):

Problem: यदि सभी zero-order correlations \(r = 0.60\) हों, तो \(R_{1.23}\) की गणना कीजिए।

Solution: \(R_{1.23}^2 = \frac{2(0.36)}{1.6} = 0.45 \implies R_{1.23} = \mathbf{0.671}\)।

4.5 Partial Correlation Coefficient (\(r_{12.3}\)) & Its Properties

The Partial Correlation Coefficient \(r_{12.3}\) measures the net linear correlation between variables \(X_1\) and \(X_2\) after eliminating (holding constant) the linear effect of the third variable \(X_3\).

Formula for Partial Correlation Coefficients

\[ r_{12.3} = \frac{r_{12} - r_{13} r_{23}}{\sqrt{(1 - r_{13}^2)(1 - r_{23}^2)}} \] \[ r_{13.2} = \frac{r_{13} - r_{12} r_{23}}{\sqrt{(1 - r_{12}^2)(1 - r_{23}^2)}}, \quad r_{23.1} = \frac{r_{23} - r_{12} r_{13}}{\sqrt{(1 - r_{12}^2)(1 - r_{13}^2)}} \]

Properties of Partial Correlation Coefficients

  • Range: \(-1 \le r_{12.3} \le 1\).
  • Relation to Partial Regression Coefficients: \(r_{12.3}^2 = b_{12.3} \cdot b_{21.3}\).
  • Total & Partial Correlation Relation: \((1 - R_{1.23}^2) = (1 - r_{12}^2)(1 - r_{13.2}^2) = (1 - r_{13}^2)(1 - r_{12.3}^2)\).

Example 4.5.1 (Calculating Partial Correlation r12.3):

Problem: Given \(r_{12} = 0.60, r_{13} = 0.70, r_{23} = 0.50\), calculate \(r_{12.3}\).

Solution:

4.5 Partial Correlation Coefficient (\(r_{12.3}\)) एवं इसके गुणधर्म

4.6 Coefficient of Determination (\(R_{1.23}^2\))

The Coefficient of Determination \(R_{1.23}^2\) represents the proportion of total variation in dependent variable \(X_1\) that is explained by the joint linear influence of independent variables \(X_2\) and \(X_3\).

Partitioning of Total Variance & Definition

\[ \text{Total SS } (\sum x_1^2) = \text{Regression SS } (\sum \hat{x}_1^2) + \text{Residual SS } (\sum e_{1.23}^2) \] \[ R_{1.23}^2 = \frac{\text{Regression SS}}{\text{Total SS}} = 1 - \frac{\text{Residual SS}}{\text{Total SS}} = 1 - \frac{\sigma_{1.23}^2}{\sigma_1^2} \]

Example 4.6.1 (Interpretation of R_{1.23}^2):

Problem: If \(R_{1.23} = 0.85\), calculate \(R_{1.23}^2\) and interpret the result.

Solution: \(R_{1.23}^2 = (0.85)^2 = \mathbf{0.7225}\). Interpretation: 72.25% of the total variation in Crop Yield (\(X_1\)) is explained by Rainfall (\(X_2\)) and Fertilizer (\(X_3\)), while 27.75% remains unexplained error variation.

Example 4.6.2 (Uncorrelated Predictors Case):

Problem: If \(r_{12} = 0.6, r_{13} = 0.8\), and predictor variables \(X_2, X_3\) are mutually uncorrelated (\(r_{23} = 0\)), calculate \(R_{1.23}^2\).

Solution: When \(r_{23} = 0\), \(R_{1.23}^2 = r_{12}^2 + r_{13}^2 = 0.6^2 + 0.8^2 = 0.36 + 0.64 = \mathbf{1.0}\) (100% variance explained).

4.8 Solved Examples

Solved Example 1: Full Trivariate Regression Analysis

Problem: In a trivariate agricultural study, standard deviations are \(\sigma_1 = 3, \sigma_2 = 4, \sigma_3 = 5\) and zero-order correlation coefficients are \(r_{12} = 0.8, r_{13} = 0.6, r_{23} = 0.5\). Calculate:

  1. Partial regression coefficients \(b_{12.3}\) and \(b_{13.2}\).
  2. Multiple Correlation Coefficient \(R_{1.23}\).
  3. Partial Correlation Coefficient \(r_{12.3}\).
  4. Residual Variance \(\sigma_{1.23}^2\).

Solution:

1) \(b_{12.3} = \frac{3}{4} \left[ \frac{0.8 - 0.30}{0.75} \right] = \mathbf{0.50}\); \(b_{13.2} = \frac{3}{5} \left[ \frac{0.6 - 0.40}{0.75} \right] = \mathbf{0.16}\).

2) \(R_{1.23}^2 = \frac{0.8^2 + 0.6^2 - 2(0.8)(0.6)(0.5)}{1 - 0.25} = \frac{0.64 + 0.36 - 0.48}{0.75} = \frac{0.52}{0.75} = 0.6933 \implies R_{1.23} = \mathbf{0.833}\).

3) \(r_{12.3} = \frac{0.8 - 0.30}{\sqrt{(1 - 0.36)(1 - 0.25)}} = \frac{0.50}{\sqrt{0.48}} = \frac{0.50}{0.6928} = \mathbf{0.721}\).

4) \(\sigma_{1.23}^2 = \sigma_1^2 (1 - R_{1.23}^2) = (3)^2 (1 - 0.6933) = 9 (0.3067) = \mathbf{2.76}\).

Solved Example 2: Symmetric Correlation Matrix Analysis

Problem: If all zero-order correlations are equal to \(r = 0.70\), calculate \(r_{12.3}\), \(R_{1.23}\), and \(R_{1.23}^2\).

Solution:

1) \(r_{12.3} = \frac{r}{1 + r} = \frac{0.70}{1.70} = \mathbf{0.412}\).

2) \(R_{1.23}^2 = \frac{2 r^2}{1 + r} = \frac{2(0.49)}{1.70} = \frac{0.98}{1.70} = \mathbf{0.5765}\).

3) Multiple Correlation \(R_{1.23} = \sqrt{0.5765} = \mathbf{0.759}\).

Solved Example 3: Uncorrelated Predictors Case

Problem: If \(r_{12} = 0.50, r_{13} = 0.50\) and \(r_{23} = 0\), calculate \(r_{12.3}\) and \(R_{1.23}^2\).

Solution:

1) \(r_{12.3} = \frac{0.50 - 0}{\sqrt{(1 - 0.25)(1 - 0)}} = \frac{0.50}{\sqrt{0.75}} = \frac{0.50}{0.866} = \mathbf{0.577}\).

2) \(R_{1.23}^2 = r_{12}^2 + r_{13}^2 = 0.25 + 0.25 = \mathbf{0.50}\).

Differentiating S partially w.r.t b_{12.3} and b_{13.2}: 1) ∂S/∂b_{12.3} = 0 ⇒ Σ x1 x2 = b_{12.3} Σ x2² + b_{13.2} Σ x2 x3. 2) ∂S/∂b_{13.2} = 0 ⇒ Σ x1 x3 = b_{12.3} Σ x2 x3 + b_{13.2} Σ x3². Dividing by n and substituting covariances and correlation coefficients yields: b_{12.3} = (σ₁/σ₂) [(r₁₂ - r₁₃ r₂₃)/(1 - r₂₃²)] and b_{13.2} = (σ₁/σ₃) [(r₁₃ - r₁₂ r₂₃)/(1 - r₂₃²)].

Q2. State and prove the 3 fundamental properties of residuals e_{1.23} = X1 - X̂1.
Solution:

1) Mean of Residuals: E[e_{1.23}] = E[X1 - X̂1] = X̄1 - X̄1 = 0. 2) Orthogonality: Σ e_{1.23} X2 = 0 and Σ e_{1.23} X3 = 0, obtained directly from least squares normal equations ∂S/∂b_{12.3} = 0 and ∂S/∂b_{13.2} = 0. 3) Distribution: Under multivariate normality of (X1, X2, X3), residual e_{1.23} is a linear combination of normal variables and follows N(0, σ_{1.23}²).

Q3. Derive the expression for Residual Variance σ_{1.23}² in terms of total variance σ₁² and correlation coefficients.
Solution:

Residual variance σ_{1.23}² = (1/n) Σ e_{1.23}² = (1/n) Σ e_{1.23} (x1 - b_{12.3} x2 - b_{13.2} x3). Since Σ e_{1.23} x2 = 0 and Σ e_{1.23} x3 = 0 by orthogonality: σ_{1.23}² = (1/n) Σ e_{1.23} x1 = (1/n) Σ x1 (x1 - b_{12.3} x2 - b_{13.2} x3) = σ₁² - b_{12.3} Cov(X1,X2) - b_{13.2} Cov(X1,X3) = σ₁² [1 - r₁₂ (r₁₂ - r₁₃ r₂₃)/(1 - r₂₃²) - r₁₃ (r₁₃ - r₁₂ r₂₃)/(1 - r₂₃²)] = σ₁² [1 - (r₁₂² + r₁₃² - 2 r₁₂ r₁₃ r₂₃)/(1 - r₂₃²)] = σ₁² (1 - R_{1.23}²).

Q4. Define Multiple Correlation Coefficient R_{1.23}. Prove its formula and list its 4 main properties.
Solution:

R_{1.23} is simple correlation between observed X1 and estimated X̂1 on regression plane. R_{1.23} = Cov(X1, X̂1) / (σ₁ σ_{X̂1}) = √[(r₁₂² + r₁₃² - 2 r₁₂ r₁₃ r₂₃)/(1 - r₂₃²)]. Properties: 1) 0 ≤ R_{1.23} ≤ 1 (always non-negative). 2) R_{1.23} ≥ |r₁₂| and R_{1.23} ≥ |r₁₃|. 3) R_{1.23} = 1 iff all points lie on regression plane (σ_{1.23}² = 0). 4) R_{1.23} = 0 iff r₁₂ = 0 and r₁₃ = 0.

Q5. Define Partial Correlation Coefficient r_{12.3}. Derive its formula in terms of zero-order correlation coefficients.
Solution:

r_{12.3} is correlation between residuals e_{1.3} (X1 regressed on X3) and e_{2.3} (X2 regressed on X3). e_{1.3} = x1 - (σ₁/σ₃) r₁₃ x3 and e_{2.3} = x2 - (σ₂/σ₃) r₂₃ x3. Cov(e_{1.3}, e_{2.3}) = (1/n) Σ (x1 - b₁₃ x3)(x2 - b₂₃ x3) = σ₁ σ₂ (r₁₂ - r₁₃ r₂₃). Var(e_{1.3}) = σ₁² (1 - r₁₃²) and Var(e_{2.3}) = σ₂² (1 - r₂₃²). Therefore, r_{12.3} = Cov / √(Var₁ Var₂) = (r₁₂ - r₁₃ r₂₃) / √[(1 - r₁₃²)(1 - r₂₃²)].

Q6. Prove the identity (1 - R_{1.23}²) = (1 - r_{12}²)(1 - r_{13.2}²) = (1 - r_{13}²)(1 - r_{12.3}²).
Solution:

Proof: From residual variance formulas, σ_{1.23}² = σ₁² (1 - R_{1.23}²). Also, regressing X1 on X3 first gives residual variance σ_{1.3}² = σ₁² (1 - r₁₃²). Next, regressing residual e_{1.3} on e_{2.3} gives residual variance σ_{1.23}² = σ_{1.3}² (1 - r_{12.3}²) = σ₁² (1 - r₁₃²)(1 - r_{12.3}²). Equating both expressions: σ₁² (1 - R_{1.23}²) = σ₁² (1 - r₁₃²)(1 - r_{12.3}²). Canceling σ₁² yields (1 - R_{1.23}²) = (1 - r_{13}²)(1 - r_{12.3}²). By symmetry, (1 - R_{1.23}²) = (1 - r_{12}²)(1 - r_{13.2}²).

Q7. Explain the Coefficient of Determination R_{1.23}² and Partitioning of Total Variance in Trivariate Regression.
Solution:

Total Variance σ₁² is partitioned into Explained Variance σ_{X̂1}² and Residual Variance σ_{1.23}²: Total SS (Σ x1²) = Regression SS (Σ x̂1²) + Residual SS (Σ e_{1.23}²). Dividing by Total SS: 1 = (Regression SS / Total SS) + (Residual SS / Total SS) ⇒ R_{1.23}² = Regression SS / Total SS = 1 - (σ_{1.23}²/σ₁²). R_{1.23}² represents the proportion of total variation in X1 explained jointly by X2 and X3.

Q8. If zero-order correlations are r_{12} = 0.6, r_{13} = 0.7, r_{23} = 0.5, calculate r_{12.3}, r_{13.2}, and R_{1.23}.
Solution:

1) r_{12.3} = (0.6 - 0.7*0.5) / √[(1 - 0.49)(1 - 0.25)] = (0.6 - 0.35) / √(0.51 * 0.75) = 0.25 / √0.3825 = 0.25 / 0.6185 = 0.404. 2) r_{13.2} = (0.7 - 0.6*0.5) / √[(1 - 0.36)(1 - 0.25)] = (0.7 - 0.30) / √(0.64 * 0.75) = 0.40 / √0.48 = 0.40 / 0.6928 = 0.577. 3) R_{1.23}² = (0.6² + 0.7² - 2*0.6*0.7*0.5) / (1 - 0.25) = (0.36 + 0.49 - 0.42) / 0.75 = 0.43 / 0.75 = 0.5733 ⇒ R_{1.23} = √0.5733 = 0.757.

Q9. Given standard deviations σ₁ = 3, σ₂ = 4, σ₃ = 5 and correlations r₁₂ = 0.8, r₁₃ = 0.6, r₂₃ = 0.5, find the plane of regression of X1 on X2 and X3.
Solution:

b_{12.3} = (3/4) * [(0.8 - 0.6*0.5)/(1 - 0.25)] = 0.75 * [0.50 / 0.75] = 0.50. b_{13.2} = (3/5) * [(0.6 - 0.8*0.5)/(1 - 0.25)] = 0.60 * [0.20 / 0.75] = 0.16. Assuming means X̄₁ = 20, X̄₂ = 30, X̄₃ = 40: (X1 - 20) = 0.50 (X2 - 30) + 0.16 (X3 - 40) ⇒ X1 = 20 - 15 - 6.4 + 0.50 X2 + 0.16 X3 ⇒ X1 = -1.4 + 0.50 X2 + 0.16 X3.

Q10. Given symmetric correlation matrix with all zero-order correlations equal to r = 0.6, calculate partial correlation r_{12.3} and multiple correlation R_{1.23}.
Solution:

1) r_{12.3} = r / (1 + r) = 0.6 / (1 + 0.6) = 0.6 / 1.6 = 0.375. 2) R_{1.23}² = 2 r² / (1 + r) = 2(0.36) / 1.6 = 0.72 / 1.6 = 0.45 ⇒ R_{1.23} = √0.45 = 0.671. 3) Residual variance fraction = 1 - R_{1.23}² = 1 - 0.45 = 0.55.
