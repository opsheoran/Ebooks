4.3 Rank-Nullity Theorem

The Rank-Nullity Theorem is a fundamental theorem connecting the dimension of the domain vector space, the rank of the linear transformation, and its nullity.

Theorem 4.1: Rank-Nullity Theorem
Statement: Let $T: V \to W$ be a linear transformation from a finite-dimensional vector space $V$ into a vector space $W$. Then: $$ \text{rank}(T) + \text{nullity}(T) = \dim V $$ where $\text{rank}(T) = \dim(\text{Im}(T))$ and $\text{nullity}(T) = \dim(\text{Ker}(T))$.

Proof:

Step 1: Let $\dim V = n$, and let nullity $\dim(\text{Ker}(T)) = k$.

Step 2: Choose a basis $\{u_1, u_2, \dots, u_k\}$ for the subspace $\text{Ker}(T)$.

Step 3: By Basis Extension Theorem, extend this set to a basis for the full vector space $V$:

$$ \mathcal{B} = \{u_1, \dots, u_k, v_1, v_2, \dots, v_r\} \quad \text{where } k + r = n $$

Step 4: Now consider the set of image vectors $S = \{T(v_1), T(v_2), \dots, T(v_r)\} \subseteq W$. We will show $S$ is a basis for $\text{Im}(T)$.

Part (i) Spanning: Let $w \in \text{Im}(T) \implies w = T(v)$ for some $v \in V$.
Write $v = a_1 u_1 + \dots + a_k u_k + b_1 v_1 + \dots + b_r v_r$.
Apply $T$: $T(v) = a_1 T(u_1) + \dots + a_k T(u_k) + b_1 T(v_1) + \dots + b_r T(v_r)$.
Since $u_i \in \text{Ker}(T) \implies T(u_i) = 0$.
Thus $w = b_1 T(v_1) + \dots + b_r T(v_r)$. Hence $S$ spans $\text{Im}(T)$.

Part (ii) Linear Independence: Suppose $c_1 T(v_1) + c_2 T(v_2) + \dots + c_r T(v_r) = 0$.
By linearity of $T$: $T(c_1 v_1 + c_2 v_2 + \dots + c_r v_r) = 0$.
This means vector $(c_1 v_1 + \dots + c_r v_r) \in \text{Ker}(T)$.
Since $\{u_1, \dots, u_k\}$ is a basis for $\text{Ker}(T)$, we can write:
$c_1 v_1 + \dots + c_r v_r = d_1 u_1 + \dots + d_k u_k \implies d_1 u_1 + \dots + d_k u_k - c_1 v_1 - \dots - c_r v_r = 0$.
Since $\mathcal{B}$ is a linearly independent basis for $V$, all coefficients must be zero: $c_1 = c_2 = \dots = c_r = 0$. Thus $S$ is linearly independent.

Step 5: Since $S$ spans $\text{Im}(T)$ and is linearly independent, $S$ is a basis for $\text{Im}(T)$.
Therefore, $\text{rank}(T) = \dim(\text{Im}(T)) = r$.
We know $k + r = n \implies \text{nullity}(T) + \text{rank}(T) = \dim V$. Proof complete.

Solved Examples for Section 4.3

Example 4.3.1: Verification of Rank-Nullity Theorem

Question: Verify Rank-Nullity Theorem for linear transformation $T: \mathbb{R}^3 \to \mathbb{R}^2$ defined by $T(x, y, z) = (x - y, y - z)$.

Solution:

Step 1: Find $\text{Ker}(T)$ by setting $T(x, y, z) = (0, 0)$:
$x - y = 0 \implies x = y$.
$y - z = 0 \implies y = z$.
So $x = y = z$. Vector $(x, y, z) = x(1, 1, 1)^T$.
Basis for $\text{Ker}(T) = \{(1, 1, 1)^T\}$. Thus $\text{nullity}(T) = 1$.

Step 2: Find $\text{Im}(T)$. Any vector $(u, v) \in \mathbb{R}^2$ can be obtained by choosing $z = 0, y = -v, x = u - v$.
Thus $\text{Im}(T) = \mathbb{R}^2$. Basis dimension $\text{rank}(T) = 2$.

Step 3: Check equation:
$\text{rank}(T) + \text{nullity}(T) = 2 + 1 = 3 = \dim(\mathbb{R}^3)$. Rank-Nullity Theorem is verified!

रैंक-नुलिटी प्रमेय: $\text{rank}(T) + \text{nullity}(T) = \dim V$।
